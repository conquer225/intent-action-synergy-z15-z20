# 板卡与硬件接口

| 板卡 | 器件目标 | 新增核 | 控制 / 数据 / 时钟 |
| --- | --- | --- | --- |
| 正点原子 Z15 | `xc7z015clg485-2` | 八通道滤波器组、CSP、方差/log2、线性 SVM | GP1 `0x83c50000` / HP2 / FCLK2 100 MHz |
| 正点原子领航者 Z20 | `xc7z020clg400-2` | 点云投影、深度测试、轨迹光栅化 | GP1 `0x83c40000` / HP2 / FCLK2 100 MHz |

原相机、HDMI、音频、共享整数核及控制地址沿用各自设计。集成脚本检查精确器件、空闲 PS 接口和地址冲突，生成新工程后对原外部端口与地址逐项比较。

Z15 使用 PYNQ 的 MMIO 与连续内存分配；HWH 读取校验器件、IP 类型与控制窗口。Z20 使用原 Linux UIO 机制，地图核独立预留 `0x06000000` 起 16 MiB DDR，并与原 NPU、显示内存区配套。

Vivado / Vitis HLS 基线为 2023.1。板卡 DDR、引脚、参考 IP、内核、设备树与原生库按对应板修准备。新增接口、整机构建和部署参数见 [PL 使用说明](../report/pl_accel.md)。
