# PL 构建与数值记录

本目录保存 2026-11-07 的实际工具报告，构建源码与根目录版本清单配对。

| 记录 | 对象与口径 |
| --- | --- |
| [eeg](eeg) | XC7Z015 CLG485，Vitis HLS 2023.1，100 MHz 目标，C 仿真、HLS 综合、Verilog 联合仿真及 IP 导出 |
| [map](map) | XC7Z020 CLG400，同一工具及流程 |
| [z15](z15) | 原 Z15 XPR 加脑电核，Vivado 2023.1 综合、资源及时序估计、集成后的完整 BD Tcl |
| [z20](z20) | 原 Navigator 双目/MLP/视频观测 BD 加地图核，同一 Vivado 流程 |
| [vectors.json](vectors.json) | 实际 HLS C++ 在电脑运行，与独立整数参考比较：脑电 5 窗、地图 3 个 720p 视角 |
| [eeg_features.csv](eeg_features.csv) | 数值算例逐窗特征、分类分数与采样计数 |

HLS `hls.json` 固定源码 SHA256；`csynth.rpt` 与 `cosim.rpt` 保留工具原文。联合仿真脑电测试台使用多种小批次和窗口，周期最小/平均/最大为 846 / 12,818 / 22,117；地图测试台含 9×9 与 63×47 场景，对应 1,111 / 30,110 / 87,295 周期。它们对应测试台调用，500 点采集窗口与 720p 显示具有各自的数据规模。

整机资源口径为逻辑综合：

| 整机 | LUT | FF | DSP | BRAM36 等效块 |
| --- | ---: | ---: | ---: | ---: |
| Z15 原显示/相机/音频 + FBCSP/SVM | 23,930 | 29,323 | 66 / 160 | 88 / 95 |
| Z20 原双目/HDMI/MLP/观察器 + Map | 29,206 | 38,946 | 48 / 220 | 20.5 / 140 |

两套整机的 `timing.rpt` 保存综合阶段的时钟、跨域路径及松弛估计；布线构建入口为 `build/pl_platform.py --implement`。构建目录使用短 ASCII 路径，`integrated.tcl` 保留当次外部 IP 目录，重建时按本机厂商资料位置传入 `--ip-repo`。

地图 GIF 为 [pl_map.gif](../media/pl_map.gif)，画面直接来自地图核的 C++ 输出。
