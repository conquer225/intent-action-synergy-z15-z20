# 当前状态

工程主线为 Z15 负责人的输入、交互和原控制链，Z20 负责相机、共享整数核和辅助显示，电脑承担部分视觉模型与渲染。三种共享核输入维度为疲劳 20、情绪 180、声音 40，复用 INT8 输入/权重、INT32 累加的 D→32 ReLU→3 数据通路。

原工程历史记录有真实 `PL_z20_mlp` 输出、整数参考一致、相机采集和眼控机构分项动作。用户确认此前已完成 Cyton 实时接收。11/01 展示快照采用 LEMON 录制特征；本次将 Z15 脑电页默认接回实时服务，并将 Z20 NPU 脑电页改为等待接收特征。声音沿用原录音输入，模型分类效果按对应数据与标签评价。

运动想象的采集适配、固定八通道 RMS EEGNet、提示试次、网页和虚拟手已包含在工程中。该分支在 Z15 ARM 运行，使用现有实验配置和固定模型摘要。实物设备沿用眼控控制链。当前运行入口见[实时 EEG 与 MI 使用说明](eeg_live_mi.md)。
