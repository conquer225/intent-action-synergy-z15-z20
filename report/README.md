# 公开版本说明

本仓库发布 Z15＋Z20 当前参赛快照中的程序源码、测试和通用 Skill。原始字节与路径映射见[来源清单](source_manifest.json)，未发布输入见[外部输入清单](external_inputs.json)。

[当前状态](current_status.md)说明已知结果与待验范围；[复现说明](reproduction.md)给出离线步骤和完整运行的前提；[来源及许可](third_party.md)说明自有与第三方内容的范围；[验证记录](verification/README.md)保存本次公开副本实际执行的检查。

参赛完整包中的历史 PDF、演示视频、海报和原始现场记录没有随程序源码公开。此仓库的公开与测试不改变历史板测或当前候选的验收状态。
