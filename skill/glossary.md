# PYNQ 验证技能包术语

| 术语 | 本包含义 |
| --- | --- |
| 载荷配对 | 同一可信构建记录所对应的 bit、HWH 及其固定摘要。文件同名只是配对检查的一项条件。 |
| 软件整数参考 | 以明确的整数位宽、舍入、缩放和饱和规则计算预期输出的独立实现。它与浮点模型的精度评价分开。 |
| 同输入核对 | 输入字节、模型工件和量化约定相同条件下，对全部输出数值的比较。类别相同不足以成立该结论。 |
| 模式版本 | 一次会话中每次切换前台任务时递增的代数，对应工程中的 epoch。 |
| 接收新鲜度 | 以接收端本机单调时钟，从实际收到某个结果起计算的有效期限。源端采集、排队和计算年龄另行限制。 |
| 会话轨迹 | 同一观察进程记录的连接、模式、接收决定与实际显示状态的时间序列。它是审计材料，与网络线上协议分别定义。 |
