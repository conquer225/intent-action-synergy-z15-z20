## 来源的保存办法

[源码索引](source_index.json)为支撑本包方法的原始文件登记相对路径、用途和 SHA256。索引不声称列全整个工程；原工程持续开发后，摘要变化应按新版本重新确认。为保持技能包独立、可公开转交，索引中的原工程文件没有整份复制进包。

[观察记录](project_observations.json)给出八项失败或观察的事实、归纳和适用边界。[脱敏摘录](project_excerpt.json)只保留原 JSON 中可核对的结果字段，并记录原文件摘要和 JSON Pointer；地址、MAC、网络凭据及私有配置不随包复制。

历史日志中的上板执行只属于原记录的日期、输入和范围。本次归档 bit/HWH 检查在电脑离线运行；没有新上板、网络恢复、真人眼控或机械测试。提示词由这些记录和接口文档提炼，没有伪造原始大模型对话，也未测量跨模型稳定完成率。
