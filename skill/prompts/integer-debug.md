# 同输入数值定位提示词

适用：RTL/HLS/PS 输出不一致、量化模型迁移或只比较了分类标签。来源：E03/E04；对应自动检查是 `scripts/compare_golden.py`。

```text
请用随附固定输入、独立参考、模型工件和实际输出定位第一个数值差异。

输入 dtype/shape/单位/布局/字节序：[填写并附实际输入]
预处理、量化、累加、舍入、缩放、饱和与溢出规则：[填写]
完整模型摘要、类别顺序及参考算法：[附材料]
参考与待验后端的全部输出、实际 backend 和运行日志：[附文件]

先验证输入、模型、量化和来源身份，再逐项比较全部输出。保留失败向量。由输入到首个差异层追踪符号扩展、权重布局、中间累加、缩放和读回。每个假设说明支持证据，给出只改变一个因素的验证及期望结果。

整数合同若要求精确相等，保留该标准。浮点容差必须有独立误差依据。最后分开报告实现一致、教师一致、真实标签正确率和调用耗时；未提供真实标签时不生成准确率。
```

失效条件：独立参考不成立、输入/模型工件缺失、只能看到最终类别或量化规则不明。此时输出可收集的最小证据，不推算不存在的中间结果。
