# 加载前审阅提示词

适用：已有 bit/HWH 和匹配硬件资料，需要交付前检查或定位加载失败。先填写材料，再将下列正文交给模型。来源：E01/E02/E03；对应自动检查是 `scripts/check_overlay.py`。

```text
请读取随附板卡信息、构建清单、bit/HWH 元数据、实现报告和当前运行日志，完成本次 PYNQ 交付审阅。

材料：
- 实物板卡、器件/封装/速度等级、板修和原理图版本：[填写]
- 系统、PYNQ、Python、工具及 IP 版本：[填写]
- 源版本、构建标识、bit/HWH 及固定摘要：[附文件]
- 应用依赖的 IP、寄存器版本、时钟和复位：[填写]
- 现有 PL/VDMA/显示所有者及退出记录：[附日志]
- 当前异常、复现步骤和最近一次正常版本：[填写]

先列事实及其文件来源，再运行可用的离线检查。逐项核对实际目标、载荷配对、IP 合同和资源所有权。不要把示例板卡或旧地址作为现场参数。

输出检查结果、第一处不一致、可复现的最小验证、预期观察和回退入口。材料不足时指出缺少哪项及其影响，不生成猜测地址或烧写命令。文件预检与实际运行验收分别给出结果。
```

失效条件：没有实物/构建身份、缺少原始错误、未知载荷格式或无法确认当前硬件所有者。先补材料，不以加载成功的假设继续写结论。
