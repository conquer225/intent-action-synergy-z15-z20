# 术语

| 术语 | 工程中的含义 |
| --- | --- |
| 输入方式 | 眼控、SSVEP、电极按压、MPU，任一时刻选择一种控制某个执行端 |
| 主模式 | 眼控、肌电、脑电三种交互方式；MPU是独立辅助任务 |
| 肌电模式 | 展示电极原始幅度、RMS和已验收触发状态，执行手开合；按压事件与收缩解释分开 |
| 运动想象展示 | 原模型左右手候选及试次提示的观察结果，首版不驱动实物 |
| 表达与媒体 | 眼控下的少量语句发声、视频浏览评分和音乐播放 |
| 执行端 | 灵巧手或倒立摆；工程中的 `pendulum` 包含滑动底座，作品称为倒立摆 |
| 电极按压 | S3 上现有电极接触/按压门限事件，用于开合；按压事件不等同于肌电分类 |
| 原始电极信号 | S3 ADC 的 0～4095 计数及采样时间，不解释为力、脑电或临床指标 |
| RMS | 完整窗口去均值后的均方根，用于展示信号幅度，未训练为意图分类器 |
| SSVEP 候选 | 原有 O1/O2 因果滤波与四频 CCA 输出；显示、质量、连续性与两完整窗口门限通过后，整合适配器才选区 |
| 启动会话 | 控制板每次重启生成的 session；重启、序号跳变和采样丢失撤销旧窗口 |
| 网络 ACK | 对端接受或拒绝命令的协议回复；机械动作验收另需反馈与现场确认 |
| PS/PL 对照 | 同一初始化、输入与定点算例在 ARM 和 FPGA 运行，比较误差、耗时和 CPU 时间 |
| 实时 / 回放 / 模拟 | 实时来自当前设备；回放来自记录；模拟来自程序生成，页面及日志明确记录来源 |
| 疲劳与情绪趋势 | 原包模型的只读参考输出，训练任务和通道保持原约定，不能替代本人准确率验收 |
