# 术语

| 术语 | 本工程中的含义 |
| --- | --- |
| FBCSP | Filter-Bank Common Spatial Patterns：三频带、每带两个 CSP 分量 |
| 采样行 | 同一时刻八个通道的微伏数据，采样率 250 Hz |
| 窗口 / hop | 参与方差计算的最近样本数 / 两次分类间的新样本数，默认 500 / 125 |
| 归一化特征 | 同一频带内每个 CSP 方差的 log2 减去该带两方差和的 log2 |
| 模型身份 | 参数及合同的 SHA256，用于核对连续运行中的模型 |
| 比较支路 | 与原分析并行消费样本、独立发布 PL 识别结果的路径 |
| epoch | 显示会话中的模式代数；切换使旧几何与旧帧失效 |
| 几何包 | 点坐标、RGB、轨迹、坐标单位与来源元数据 |
| 观察矩阵 | 将源几何移到显示观察坐标的 3×4 定点变换 |
| 显示所有者 | 既有负责最终 HDMI 帧提交的对象 |
| 缓冲所有权 | 从硬件启动到完成或已确认复位期间，DDR 缓冲由该命令持有 |
