# Z20 计算扩展术语

| 术语 | 本工程中的含义 |
|---|---|
| 无线视觉会话 | 电脑渲染连接建立时生成的独立标识；重连替换会话，拒绝旧画面 |
| 展示模式版本 | 同一会话中每次选模式、换样本、重新拍摄递增的 epoch；计算和画面必须匹配 |
| 顺序声谱窗口 | 按录音播放位置提取的1024点FFT窗口，记录实际采样偏移与循环序号；不播放声音 |
| NPU结构示意 | 32个节点代表网络结构；由真实提交/完成事件触发提示，不代表隐藏层激活读回 |
| 分类过程展示 | 同一输入窗口的来源、特征、计算状态、分类得分和结果；每个结果保留输入标识 |
| 单次声音输入 | 电脑麦克风或WAV提供的一秒16kHz单声道样本，提取40维特征供共享分类核心计算 |
| 同输入耗时对照 | 同一模型、同一特征的预测调用耗时比较，包含量化，排除采集与无线传输 |
| 独立视频通路 | 相机、PL 采集、VDMA 和显示自行持续工作；分析程序不负责逐帧输出 |
| 被动帧观察器 | 只记录采集写入及完成事件，不控制采集或显示节奏的帧状态观察逻辑 |
| 旁路快照 | 从最近完成、当前未被写入的帧缓冲复制出的只读分析输入 |
| 写入代数 write_epoch | 每次开始写一帧都增长的计数，用来识别循环缓冲绕回；不能用缓冲索引代替 |
| 最新任务槽 | 一个正在处理的任务加最多一个待处理任务，后来的输入替换待处理旧输入 |
| 模式代数 epoch | 前台切换时增长的计数；旧代数的计算结果自动失效 |
| 共享 NPU | 同一个 INT8 全连接 D→32 ReLU→3 核心，按任务加载不同权重 |
| 分类器输入特征 | 原预处理已经完成、直接交给原分类器的向量；情绪为 180 维、疲劳为 20 维 |
| 特征窗口 | 一份带来源、预处理版本、质量和窗口编号的分类器输入，不等同于原始波形 |
| 教师一致性 | 新模型与原模型在相同输入上的结果一致程度，与真人状态准确率分别记录 |
| 教师特征探针 | 为检查或拟合原模型而构造的特征向量，不代表录制脑电或真人状态标签 |
| 接收新鲜度 | 从本机接收输入起计算的有效期限，不依赖两台设备的时钟同步 |
| 辅助观察钩子 | 取得原分类器输入副本的可撤销观察点，保留原分类过程及返回值 |
| 固定图片记忆 | 记住预先登记的图片，并根据输入像素区分它们；验收范围为登记图片的回忆 |
| 固定场景记忆 | 识别已登记的人狗同框演示图片；结果只对登记的场景成立 |
| 视频标注回放 | 按视频源时间戳插值人工复核的框、读取片段行为标注，并计算当前帧的参考尺寸深度；尚未使用行为识别模型 |
| 平板照片配准 | 从相机实际采集像素提取特征，与登记照片做平面配准，再将登记框映射到当前画面；未知或过期输入清空结果 |
| 照片演示抽样 | 从每路 640×720 原始环按横纵各 4 取样，再在普通内存把主视图从 160×180 放大到 320×360；保持纵横比，减少非缓存读取时间，不绑定米制标定 |
| 屏幕平面距离 | 双目摄像头到平板屏幕的物理距离；与照片内容中的人狗距离分别记录，未实测标定时保持无效 |
| 独立叠加显示环 | 在启动时预留的 0x04000000、8294400 字节显示缓冲；与相机写入环分离，照片演示通过 MM2S 读取 |
| 登记框 | 人工核对并保存的某张演示图中人或狗的矩形位置，不是每次输入都重新检测出的框 |
| 人狗交互标注 | 对登记场景记录的抱着、抚摸或牵着关系；由识别到的场景取用 |
| 水平位置关系 | 以人框和狗框的水平中心比较得到的人在狗左边、右边或中心相同 |
| 参考尺寸深度 | 以登记参考段的像素长度和尺寸先验，按 Z=fL/l 得到的相机方向深度估算 |
| 人狗中心间距 | 以登记框中心反投影得到两个相机三维点后计算的欧氏距离，单位为米 |
| 软件整数参考 | ARM 或电脑运行的同一定点算法，结果标识为 PS_integer_reference |
| 背景脑电 | 独立于人脸／双目模式的连续脑电滤波、校准与窗口状态 |
| 录制组 group | 同次录制、同次会话及其派生窗口的共同标识；整组进入一个数据划分 |
| 无效结果 | 缺少信号、模型、标定或结果超时时的状态，class_id 与 scores 清空 |
| DAC 频谱扫描 | 按频率递增输出冻结的幅度数组，首个频点给同步标记 |
| 点云位姿 | 相机坐标到世界坐标的 4×4 刚性变换，平移单位为米 |
| deployable | 模型来源声明为 recorded 或 public；它只是来源检查，准确率与现场验收另外记录 |
| 采集行宽 | 每路相机一行有效像素所占的字节数 |
| 合成行跨度 | 在左右合成画面中，相邻两行起点之间的字节数 |
| 写完成确认 | 一帧的所有有效像素写请求均收到成功响应后，才把该帧标记完成 |
| 双目帧配对 | 旧入口按相同完整帧序号配对；无屏入口按硬件完成时间配对，最大差 5 ms，允许计数固定偏移和各路使用不同槽，仍检查覆盖及过期；不表示传感器曝光同步 |
| 完成时间配对采集模式 | `z20-observer-q4-bgr-gray160x180-completion5ms-v2`；每路 160×180 灰度，完成时间差不超过 5 ms，标定文件必须绑定该模式 |
| 源录音平衡 | 先给各类相同权重，再给类内各源录音相同权重；同一录音切出更多窗口不会增加该录音的总权重 |
| 领航者目标 | 实际接入的ATK-DF7010/7020P板卡，与此前按新版Z20资料准备的目标分开识别 |
| 启动预留内存 | Linux启动前划出的专用内存，系统普通分配器不能占用 |
| 假设参数点云 | 用明确列出的镜头和安装假设从真实图像重建的实验点集，形状与实际尺寸尚未独立验证 |
| 伪激光雷达点云 | 由双目图像的视差反投影得到、形式类似激光雷达输出的三维点集；当前无标定预览属于假设参数点云，单位为相机基线长度 |
| 单目预测表面 | 由单张 RGB 图的模型预测深度反投影得到的当前可见表面；深度、相机内参及尺度验证状态随结果保存 |
| 深度中位数单位 | 将一张预测深度图除以其有效像素中位数得到的相对坐标尺度，不代表米或相机基线长度 |
| 领航者 J4 AD/DA 约束 | ATK-DF7010/7020P 上供 MC8008 使用的 19 根数字信号的 CLG400 球号；连接器物理针号和供电方向另按实物核对 |
| 板载音频目标 | 以 ES8388、MIC、喇叭/耳机为通路的独立 PL 测试工程，先测声音，再接 HDMI 与共享固件 |
| 旁路快照计数 | 状态中的 camera_frames：CPU成功复制的新鲜相机快照数；传感器帧率另由PL完成帧计数测量 |
| 模式确认状态 | 控制命令ACK返回的会话、模式与epoch；电脑立即采用，较旧轮询不得回退此版本 |
| 单相机展示快照 | 空间展示仅复制左相机的完成槽，用于单目网络；仍检查覆盖和年龄，不能当作已配对双目测距输入 |
