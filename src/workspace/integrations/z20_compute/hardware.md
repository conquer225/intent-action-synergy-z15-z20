## NPU 接口

器件目标为 xc7z020clg484-2，时钟约束 10 ns。已有HLS IP首次接入官方视频BD副本，经HP1访问DDR，控制基址为0x40000000；BD验证返回0，顶层综合已完成，布局布线及候选bit／XSA已完成，外部IO时序与板测尚未完成。该器件与现有核心板具体丝印、速度等级还应在工程入口再次核对。

| 接口 | 连接要求 |
|---|---|
| s_axi_control | PS AXI GP 控制互连，地址由完整 BD 的 assign_bd_address 结果提供 |
| m_axi_samples／m_axi_weights | 经 AXI 互连接 PS DDR 可达的 HP 通道，保持地址宽度和缓存策略一致 |
| ap_clk／ap_rst_n | 与所接 AXI 互连一致，复位完成后再访问 |
| 控制偏移 | input 0x18，w1 0x24，b1 0x30，w2 0x3c，b2 0x48，output 0x54；每个指针低／高两个字 |
| 标量偏移 | input_size 0x60，hidden_shift 0x68，return 0x10，控制 0x00 |

偏移来自 Vitis HLS 2023.1 生成的驱动头文件。更换导出版本后先对照头文件再运行。驱动要求分配器提供 physical_address、flush、invalidate、freebuffer；本机同时使用假寄存器及实际 mmap 文件验证读写、缓存同步请求和内存保留行为。NPU 超时或启动后 MMIO 失联时保留缓冲，确认 PL 已复位后才能释放。

HLS 综合估算为 4 DSP、9 BRAM_18K、4599 FF、5355 LUT，估算周期 7.300 ns。它只覆盖这个 IP。整板资源与时序以当前 stereo_hardware_build.json 对应报告为准；带宽和端到端耗时须实板测量。

## 视频与外设接线约束

双目接 J22，AD/DA 的同时连接方案后排。两块外设各自可以直插套件接口，共用 J22 时不能同时插入；FMC 转接是可评估方案。已从新板手册恢复 hardware/z20_dual_camera_candidate.xdc，38个管脚及资料冲突见 report/board_adaptation.md。约束已有完整实现证据，外部 I/O 延迟与实板电气验收仍需测量。相机 DVP PCLK、视频 AXI 时钟、PS 总线之间由官方采集和视频 IP 处理跨时钟，新增观测寄存器与 VDMA 内存时钟同域，ARM 通过 AXI 时钟转换器读取。

独立视频路径先在完全不启动分析的情况下运行，再把快照旁路接入。显示 DMA 和相机 DMA 均不能等待分析线程；快照拷贝需要使非一致缓存失效，并比较完整、稳定读取的写入代数与完成序号。若现有工程不能提供这一状态，先补硬件状态观测，不冒用原视频的 VSYNC 数值作为缓冲所有权。

DAC 流模块的 sample_tick、AXI Stream 与内部 clk 同域。实际 DAC 时钟应由经过约束的时钟／IO 资源输出，验证建立保持时间和有效边沿；不得把普通逻辑生成的异步脉冲直接当转换时钟。TDATA[8] 的扫描标记在对应 DAC 采样间隔有效，可由转接板导出到示波器触发输入。模拟增益、直流偏置、负载与重建滤波由 MC8008 实际资料确定。

## 接板后按顺序记录

1. 固定官方镜像、Vivado／Vitis 版本和 BOOT 文件摘要，先验证串口、DDR、网口与官方连续视频。
2. 保持相机和显示运行，让分析延迟一秒、超时和暂停；分别记录采集帧率、HDMI 刷新率和结果更新率。
3. 比较 DMA 快照前后代数和实际图像，确认绕回、缓存与左右帧同步；测量拷贝及访存开销。
4. 对四种输入尺寸运行同一定点模型的软件与 PL 对比，再测试连续调用、切换权重、超时与复位恢复；记录核内和端到端耗时。
5. 使用多个独立已知距离测距，记录纹理、光照、左右曝光、误差和无效比例；遮挡后立即清除旧距离。
6. 审核电气接线后，用低幅度已知音调验证 ADC 采样、FFT 峰值、DAC 原波形、滤波输出、频谱扫描同步和切换瞬态。
7. 采集真实训练／验证／测试会话；三类均分别报告结果，加入空框、未录入人、静音和脑电质量不足样本。
8. 脑电后台持续、人脸／双目前台切换、声音按需启停；拔网线后旧结果失效，原 Z15 控制继续运行。
