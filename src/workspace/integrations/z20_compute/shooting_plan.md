# 三分钟视频拍摄清单

主线原片预算 280 秒，成片 178 秒。先完成无线、实屏和执行器回归，再按此清单录两遍。全程保留 USB Wi-Fi、双板分工和电脑辅助计算的事实说明。

手机横屏、支架固定，优先1080p/30fps。两屏并排，操作者侧坐；锁定曝光与焦点，检查屏幕是否有条纹。场内保持静音，旁白、配乐后期加入。

选择、注入、机械动作的因果关系保留连续原速镜头。脑电等待和深度生成可裁剪或加速，画面标明“等待已加速”。电脑录屏只补充细节，不能替代各新增模式首次出现的实屏镜头。

空间段先拍纹理清楚、边缘完整的书本或纸盒。第一次拍摄保存输入标识和结果，再改变物体位置拍第二次，防止把旧三维结果误作新图。可见表面只小角度摆动观察，画面不出现未经验证的米数。

NPU 段必须使用实际PL后端和实际核对结果；软件参考只能用于排练并保留对应标识。误分类保留真实得分，可以换另一个已经记录的样本，但不能改标签或伪造输出。若无线吞吐或PL/HDMI现场验收未通过，先处理失败项，不用有线录像代替无线验收。

肌电、三人身份识别和其他七种图像效果不进入成片。Z15第三、四页已按最新要求恢复，可在脑电段中替换少量重复波形镜头；178秒总时长保持。NPU段优先拍疲劳／情绪的输入特征、分类结果和真实耗时对照，声音分类另用同一输入做补充。原设备控制和主动停止优先于视觉镜头。
