# 我们意念合一：眼控灵巧手与倒立摆

本目录以 `GuardianLoop_team_20261017_03(1).zip` 为基线维护眼控设备操作。2026-10-30 修订简化操作并修复已复现的回退路径，当前修订尚未部署到板卡。已部署双板工程应使用 [本次配套更新](../z20_compute/report/device_menu_20261030.md)，下方原始安装流程适用于其原基线。

## 页面与操作

首页左区改为“设备与方向”，中区“交流表达”、右区“多媒体”保留。进入左区后，三个区域分别是灵巧手、倒立摆、原速度与方向。

| 页面 | 左区 | 中区 | 右区 |
| --- | --- | --- | --- |
| 设备与方向 | 灵巧手 | 倒立摆 | 原速度与方向 |
| 灵巧手 | 张开 | 停止操作 | 闭合 |
| 倒立摆入口 | 平衡启停 | 返回设备 | 左右单圈 |
| 倒立摆平衡 | 启动平衡 | 停止操作 | 停止平衡 |
| 倒立摆短动作 | 左转一圈 | 停止操作 | 右转一圈 |

进入动作页后自动准备一次连接，页面呈现、阅读保护和有效眼动检查通过后才发送请求。回执到达后先刷新状态，再允许选择动作。原三点标定、快速检查、停留选择、换区解锁和阅读保护保留。断连时动作标签不变，选择侧区只重新连接，确认就绪后再选动作。

中区第一次只停止并留页，随后变为“返回设备”或“返回倒立摆”。持续注视不连退；换区后再次确认中区才返回。情绪选歌提示不接管设备页，严重疲劳警示仍会停止控制。

手机原“主页”“强制停止”和 PS_KEY1 暂停也会撤销执行端控制。失去新鲜有效眼动、重新标定、显示循环停止服务或网络断开会关闭普通眼控控制会话；重连需要新的选择。机构是否停止仍需现场观察，网络回执不代表机械运动完成。倒立摆“停止平衡”沿用原协议，撤销全部控制选中区“停止操作”。

软件预览见 [页面总览](report/previews/overview.png)，其中的连接和启用状态由测试输入生成。

## 网口与 C3 局域网

实际控制链路是：Z15 网口 → 无线网桥或桥接路由器 → C3 热点局域网 → S3 的 TCP 9000。灵巧手经 S3/RF-Nano 执行；倒立摆经 S3/C3/STM32 执行。C3 地址 `192.168.4.1` 是热点网桥地址，不是 TCP 9000 控制服务器。

C3 没有以太网口。若 Z15 使用网线，需要让接网线的路由器或无线网桥加入 C3 的 `NaoDun-Control` 热点，并桥接到其 `192.168.4.0/24` 网络。也可使用已正确桥接的电脑网卡。热点密码继续用原本机配置，本包不包含密码。Windows“Internet 连接共享”通常会新建其他网段，不能仅打开共享就认定桥接完成。

2026-10-11 的部署记录中 S3 是 `192.168.4.2`；这是历史实测地址，安装前从 S3 的 `link` 或 `stream status` 核对当前地址。Z15 和 S3 地址不能冲突。在 Z15 上执行以下只读检查，预期路由的 `dev` 是接网线的接口，随后能访问 S3 的 9000 端口：

```sh
ip -4 addr show eth0
ip -4 route get 192.168.4.2
python3 -c "import socket; s=socket.create_connection(('192.168.4.2',9000),2); print('TCP 9000 reachable'); s.close()"
```

用现场地址替换例子中的 `192.168.4.2`。两条软件命令不会修改网络配置或启用机构。设备端的 C3、S3、STM32 和 Nano 固件保持现有版本。

## 在现有 Z15 运行目录安装

完整交付 ZIP 保留原工程，并在 `eye_c3_update/` 放置这次更新。`runtime/` 是供检查与测试的源码集合；实际安装只替换 `media_player.py`、`system_hdmi.py`，增加三个设备模块及地址配置。安装脚本同步更新现有 `boot-pins.json` 中的对应摘要，保留其他条目。原媒体、评分、密钥、网络配置、模型和 FPGA 产物不在替换范围内。

1. 在原手机面板结束显示会话，等待原程序完成显示停止、缓存释放与原 overlay 恢复。安装脚本发现活动播放器或未完成的退出记录会拒绝写入。
2. 把更新目录复制到 Z15，例如 `/home/xilinx/eye_c3_update`。使用板上原 PYNQ 环境的 Python，先预检：

```sh
cd /home/xilinx/eye_c3_update
sudo /usr/local/share/pynq-venv/bin/python3 install_patch.py \
  --runtime /home/xilinx/gl-hdmi-live-20261008-ea117349 \
  --s3-host 192.168.4.2
```

3. 预检通过后，用同一命令加 `--apply` 安装。它会输出备份目录；原文件的摘要必须与本包基线相符，版本不同会停止，不会强行覆盖。
4. 从原手机面板重新开启显示。用 PS_KEY0 开始原眼控流程，完成标定和快速检查，然后进入“设备与方向”。等待设备就绪后分别验证手开合、倒立摆平衡与左右动作。

本包不会自动上传、修改网络或启动机构。缺少 `eye_devices.json` 时，播放器沿用原控制入口。配置格式如下，其中地址由安装脚本按 `--s3-host` 写入：

```json
{"version":1,"s3_host":"192.168.4.2","s3_port":9000}
```

回退时先结束显示会话，再执行：

```sh
sudo /usr/local/share/pynq-venv/bin/python3 install_patch.py \
  --runtime /home/xilinx/gl-hdmi-live-20261008-ea117349 \
  --rollback /home/xilinx/gl-hdmi-live-20261008-ea117349/.eye-c3-backups/install-实际目录名
```

回退同时恢复原启动摘要；安装后又被人工修改的文件会先报出，不会覆盖后续修改。
