# 演示页术语

| 术语 | 含义与代码位置 |
| --- | --- |
| 实时观测 | 共享只读缓存的一次有效采集快照；DemoBridge.snapshot |
| 处理摘要 | 已执行计算的窗口、实际特征和配置，不执行另一套识别；processing_snapshot |
| 当前窗口 | 当前已收集样本范围；processing.window |
| 特征窗口 | 最近一次真正计算并通过有效性检查的样本范围；processing.feature_window |
| 疲劳分数 | 原 HGB 输出及原有 EMA 处理结果，范围 0～1，不是识别置信度 |
| 历史回放 | 人工选择的本机展示遥测记录，保持原时间间隔，固定历史标识 |
| 缺失区间 | 采集失效或未收到新数据的时段；清除结果并断开波形 |
| 请求已提交 | 链路已接收软件请求；不等于设备回执或机构已完成动作 |
| 设备回执 | S3 控制协议的响应；机械结果需独立观察 |
| 调试保持 | 用户显式选择的调试方式：移开视线或显示续约中断时保留设备启用，直到主动停止、退出控制页面或连接断开 |
