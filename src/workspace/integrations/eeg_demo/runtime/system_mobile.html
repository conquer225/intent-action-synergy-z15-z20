HDMI 与眼控

操作说明

操作顺序：启动 HDMI → 开始眼控定位 → 调整至双眼有效后点击“位置已就绪，开始三点标定” → 跟随白点 → 中／左／右各确认一次。初始化失败可点重新连接；不会自动重做已完成标定。方向页保持现有四角布局；测试期自动退出是否开启以实时状态为准。

手机轮椅遥控／联合运行

等待核对接收端输出模式，不要操作方向。

操作说明

持续遥控版：点方向后持续执行，不需要长按，也无固定行驶时长；点停止撤销驱动，换方向先停车再切换。必须保持此页面在前台，断网、锁屏、退出或程序异常时撤销输出；恢复连接后需重新点方向。停止后保持手动停止，只有主动切回 SSVEP 才恢复脑控接口。网页停止不是独立物理急停。

眼控负责菜单、虚拟速度档位和多媒体；进入方向页自动显示四角闪烁，无有效脑电时不产生方向。方向页只启用中央眼控返回框。情绪／疲劳持续监测，严重疲劳保持方向锁定。

视频库／收藏

点赞后保存在收藏入口，原视频留在板卡。“保存到手机”需点击下载并由手机确认；不会把收藏标记当作已下载。

手机观看

先从板卡读取所选视频，再在手机播放；默认静音。这不是手机录屏或实时镜像。较大文件请用HDMI播放或下载。

上传新视频
