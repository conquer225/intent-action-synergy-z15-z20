# 图像扩展术语

| 术语 | 工程含义 |
|---|---|
| 模式 | PL_KEY0 选中的一种画面处理；0–8 为 OV5640，9 为 Tobii |
| 来源代次 generation | 每次模式或源切换递增，用于拒绝上一代延迟帧 |
| 新鲜帧 | 采集时间距当前不超过 1.5 秒，且序号、时间未倒退 |
| 瞳孔候选 | 通过眼区及椭圆检查的观测，不是原眼控标定结果 |
| 源坐标 | Tobii 原图的像素位置，未按 HDMI 显示尺寸缩放 |
| PL 处理核 | 由可编程逻辑执行所选图像变换的模块 |
| 资源保留 | DMA/HLS 未停止时保留 CMA；确认 PL 恢复后才释放 |
| 合成预览 | 用测试图案展示版式和算法，不代表真人或板卡性能 |
| 连续视频 | 相机持续产生新画面，显示读取不等待软件分析完成 |
| 相机更新率 | 单位时间内相机产生的新帧数量 |
| 显示刷新率 | 单位时间内 HDMI 扫描次数，允许重复上一帧 |
| 流式滤镜 | 随输入像素连续处理，不以软件提交整帧作为显示前提 |

| 信号页 | PL_KEY1 选择的疲劳、情绪、脑电音乐联动或音乐音频分析画面 |
| 推理确认 | 不同实际特征窗口支持同一音乐状态；重复发布同一结果不累加 |
| 源 PCM 分析 | 读取当前播放文件、播放器报告位置对应的样本，处于音量和输出器之前 |
| 历史原算法结果 | 对公开记录离线调用原模型形成的结果，与真实波形按原时间关系回放 |
| 选曲事件 | 一次有效脑电决策及其播放请求；保存来源时间位置，不代表现场听音确认 |

- 展示记录（presentation recording）：默认载入的真实 LEMON EEG 及原模型处理结果；保持记录来源，不表示当前佩戴采集。
- 展示主题（presentation theme）：网页与 HDMI 共用的暖色配色、文字层级与状态规则；采样目标和执行逻辑保持原约定。
