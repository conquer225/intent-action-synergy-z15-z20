这是原 PYNQ/Linux SD 环境上的成套更新包，包含完整原工程，不是可直接写入空白 SD 卡的系统镜像。目标需已有原工程的媒体、脑电和眼控三个目录，以及其实际发布清单、共存引用和启动摘要。不能用示例状态覆盖现场状态。

## Z15 成套安装与回退

在 `presentation_release` 目录操作。以下三个根路径来自现有实板；异机按实际路径替换。

若目标已安装旧图像／四页扩展，先用它实际保存的 `INSTALLED_BACKUP`，按安装相反顺序逐次严格回退到原基线，再执行新安装。备份目录中的事务记录包含安装前后摘要；未知版本或回退后仍有后续改动时，安装器会停止。不要从历史说明复制某个固定备份编号，也不要直接覆盖运行目录。

```bash
sudo /usr/local/share/pynq-venv/bin/python3 integrations/vision_demo/install_vision.py \
  --media-root /home/xilinx/gl-hdmi-live-20261008-ea117349 \
  --brain-root /home/xilinx/jupyter_notebooks/guardianloop_pynq \
  --eye-root /home/xilinx/brain_eye_coexist_20261005/eye \
  --rollback <该目标最后一次安装保存的备份目录>
```

若目标尚未安装脑电／眼控设备基础更新，先按 `integrations/eeg_demo/README.md` 运行该目录的安装器；其 `--s3-host` 填现场地址，已有设备配置保留。当前实板 S3 曾使用 `192.168.50.45:9000`，仍须从现场状态核对。已具备基础更新的目标直接预检展示包：

```bash
sudo /usr/local/share/pynq-venv/bin/python3 integrations/vision_demo/install_vision.py \
  --media-root /home/xilinx/gl-hdmi-live-20261008-ea117349 \
  --brain-root /home/xilinx/jupyter_notebooks/guardianloop_pynq \
  --eye-root /home/xilinx/brain_eye_coexist_20261005/eye --bundle ./bundle
```

预检通过后，同一命令增加 `--apply`。保存输出的新 `INSTALLED_BACKUP`，再恢复原服务。安装器成套更新发布清单、共存校验引用、显示状态摘要与启动摘要，检查 FPGA 寄存器地址及模型保护。需要撤销本次安装时，先停止服务、确认资源归还，再用同一安装器和三个根路径执行 `--rollback <新备份目录>`；基础更新的回退由它自己的安装器执行。
