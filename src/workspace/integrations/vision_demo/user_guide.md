# 我们意念合一：完整使用指南

适用版本：GuardianLoop_Submission_20261020_r2.zip。整理日期：2026-10-20。

## 1. 先选对使用方式

本指南以最新 r2 展示包为准。当前电脑预览已更新；按最后一次部署记录，Z15 仍保留此前安装版本，新热力图、四页音乐和联合流式图像包尚未整体部署。

| 你现在要做什么 | 使用入口 | 需要什么 |
| --- | --- | --- |
| 电脑查看脑电与音乐演示 | 浏览器打开 http://127.0.0.1:9130/ | 电脑、Python 环境、本地素材 |
| 手机管理实物系统 | 手机连接 Z15 原热点，打开板端控制台 | Z15 正式服务、原访问码 |
| 实物眼控灵巧手、倒立摆 | HDMI 主页的“设备与方向” | Tobii、S3、对应执行端 |
| 实物查看新版图像与四页演示 | 新版安装后按 PL_KEY0 / PL_KEY1 | Z15、HDMI；图像部分另接摄像头 |

电脑预览监听电脑自己的回环地址。手机上的 127.0.0.1 指向手机本身，不能用它访问电脑或板卡。当前 9130 预览的控制台只展示页面，不向机构发送命令。

### 电脑最快开始

1. 完整解压 r2 工程包，进入 GuardianLoop_team_20261017_03 文件夹。
2. 双击 START_PRESENTATION.cmd，保留终端窗口。
3. 浏览器打开 http://127.0.0.1:9130/。
4. 点击顶部四个导航按钮切页。首次进入音乐联动页，点击“播放音乐”允许发声。
5. “暂停展示”冻结记录时间并停止音乐；“重新开始”回到记录起点、清除旧选曲。

本机服务已经启动时，直接打开页面；再次启动提示端口占用时，使用已有服务。换电脑需要 Python、NumPy、SciPy、Pillow、OpenCV。可先检查环境：

```powershell
python -c "import numpy, scipy, PIL, cv2; print('READY')"
```

若缺少依赖，在电脑 Python 环境安装：

```powershell
python -m pip install numpy scipy Pillow opencv-python
```

该安装命令只用于电脑。Z15 继续使用原 PYNQ 环境，避免替换板端依赖。装好依赖后，页面、脑电记录和音乐均可离线使用。

## 2. 设备分工与连接

Z15 的 PS 运行系统、眼控菜单、原脑电模型、网络协调与播放；PL 负责 HDMI、视频搬运、连续图像滤镜和新增音频 FFT。倒立摆的启摆与平衡算法继续由 STM32 执行。

```text
Tobii → Z15 眼控菜单 → Wi-Fi → S3 → 原 RF 手端 → 灵巧手
                               └→ BLE → DX-BT24 → STM32 → 倒立摆
OV5640 → Z15 PL 视频滤镜 → HDMI
真实脑电记录 → 原模型处理结果 → 脑电四页 → 音乐选曲与音频分析
```

| 设备或接口 | 接法与用途 |
| --- | --- |
| Z15 电源与 SD 卡 | 使用原稳定电源和已验收 PYNQ/Linux SD 卡 |
| HDMI | Z15 接显示器；听音乐时使用已接通的 HDMI 音频设备 |
| Tobii | 按原 USB 接法接 Z15，放在原眼控使用位置 |
| OV5640 | 保留本工程原摄像头接口与排线方向，断电接插 |
| Z15 USB 无线网卡 | 保留原热点配置，S3 与手机加入该网络 |
| S3 | 保留原独立供电、无线手端及其他接线；USB 串口供调试 |
| 灵巧手 | 保留原接收端、舵机电源与校准 |
| 倒立摆 | STM32 与电机使用原共同供电；串口接 DX-BT24 |
| PS_UART / 下载线 / 网线 | 用于调试或维护，日常无线控制不依赖电脑串口转发 |

S3 曾在 USB 供电时反复重启，当前使用已确认稳定的独立供电方式。插入调试线后，仍需确认没有重新出现复位。COM18、COM27 等是本机历史端口号，更换电脑或 USB 口后可能改变。

### DX-BT24 与 STM32 接线

断电后按排针丝印连接，不按照片左右方向猜测。

| DX-BT24 引脚 | 连接 |
| --- | --- |
| RXD | STM32 PA9，即 UART1 TX |
| TXD | STM32 PA10，即 UART1 RX |
| GND | STM32 GND、独立 3.3V 电源负极，共地 |
| 3.3V | 独立 3.3V 电源正极 |
| 5V、STATE | 悬空 |

USB-TTL 不再接蓝牙模块的 RXD/TXD。C3 和 ESP8266 保留为后续替换方案，当前不接入这对串口，也不与蓝牙模块同时驱动 STM32 PA10。蓝牙连接由 S3 建立，Z15 不直接连接该模块。

### 上电前与正常启动

1. 先检查接线、共地和独立电源。灵巧手周围不夹物，倒立摆小车居中、摆杆处于原待机位置，行程与摆动范围留空。
2. 先启动 Z15 和显示器，让原正式服务正常运行，再启动 S3 与蓝牙模块。启动过程保持执行机构断电或处于可控待机状态。
3. 当前 S3 保留原手端开机行为，手端上电可能动作；上电前人员离开手指和连杆。
4. 连接手机控制台，确认 HDMI 主页和设备状态。准备动作测试时再给相应机构正常供电，先等待新的就绪回报。
5. 每次重新上电、重新连接或返回设备页面后，重新进行页面中的明确启用操作。

## 3. 手机控制台与 HDMI 主页

手机连接 Z15 的原 Wi-Fi 热点，使用之前保存的带访问码链接。当前启动源码配置的正式媒体端口为 9119；现场地址以板端实际服务为准。地址结构为：

```text
http://<Z15局域网IP>:9119/#<原访问码>
```

尖括号部分是说明占位符，需要换成实际值。原访问码和网络密码不写入本指南，也不要删掉链接中的 # 后内容。S3 的 TCP 9000 是设备通信端口，不是手机网页端口。

页面为暖金色纵向控制台，向下滚动可见扬声器、脑电入口、HDMI 与眼控、原方向/SSVEP 区域、视频库和上传。旧栏目中的“轮椅”“虚拟方向”属于原保留接口，不等于倒立摆启停按钮。眼控倒立摆从 HDMI 的“设备与方向”进入。

| 控件 | 用途 |
| --- | --- |
| 启动／恢复 HDMI 主页 | 打开或恢复正式主页 |
| 开始眼控定位与三点标定 | 开始 Tobii 连接、位置确认和标定流程 |
| 返回主页 | 退出当前页面，撤销当前设备控制 |
| 停止眼控 | 停止原眼控流程 |
| 停止显示并恢复 PL | 完整结束显示会话并恢复原 overlay，维护前使用 |
| 顶部强制停止 | 提交停止请求；观察回执和机构状态 |
| 数字音量 | 调整软件音量；显示器自身音量另用屏幕按键调整 |
| 脑电处理与状态分析 | 打开波形、特征与结果全景页 |

点击停止后，确认页面回执与实物已经停止。网络中断时，页面不能确认停止是否执行；必要时直接切断机构电源。

## 4. 四个板载按键

| 按键 | 最新版用途 |
| --- | --- |
| PL_KEY0 | 进入图像模式；每按一次切换下一个图像模式 |
| PL_KEY1 | 进入脑电音乐四页；每按一次切换下一页 |
| PS_KEY0 | 原眼控开始／确认；在图像或脑电演示中先退出，并按当前眼控状态处理 |
| PS_KEY1 | 原眼控暂停／继续；演示中退出并停止音乐，设备控制按暂停流程撤销 |

PL_KEY0 和 PL_KEY1 按一次后松开，再按下一次；长按不会反复切页。不要同时按两个 PL 键；同时按下后需要全部松开，才接受下一次单键操作。旧 multimodal 目录中“KEY0 三模式、KEY1 全局停止”的说明不适用于本 r2 展示入口。

正在进行眼控标定或快速检查时，先完成流程，或用 PS_KEY1 停止，再进入图像或脑电展示。

## 5. 眼控标定与选择

1. 在控制台点击“启动／恢复 HDMI 主页”。
2. 点击“开始眼控定位与三点标定”，或按 PS_KEY0 进入原开始流程。
3. 坐在原眼控位置，移开遮挡物，调整至系统确认双眼有效。
4. 按页面提示确认“位置已就绪，开始三点标定”。跟随屏幕白点，完成原三点标定和快速检查；不要在过程中切换图像源。
5. 返回主页后，注视对应区域，等待停留进度完成。一次选择后看向其他区域，再回来看原区域，才能重新触发。
6. 切页后先读屏，等阅读保护结束再选择。连接失败或重启眼控进程后，按提示重新连接和标定。

主页左侧是“设备与方向”，中间是“交流表达”，右侧是“多媒体”。当前目标按屏幕字样选择，不能把眼动仪图像中的瞳孔圈选当作眼控标定完成。

### 调试保持的实际行为

按最后一次部署记录，设备控制配置启用了 debug_hold=true。它允许单人调试时移开视线，页面不会因为视线或显示续约期限自动停用。暂停、切页、停止并返回、显式取消和 TCP 断开仍撤销会话，底层通信超时仍保留。

动作结束后主动选择停止或返回。移开眼睛不等于停止。重新安装或回退后以板端配置和页面状态为准，不能假定配置始终相同。

## 6. 灵巧手与倒立摆

### 灵巧手

1. 从主页进入“设备与方向”，再选“灵巧手”。
2. 初始页面左侧为“启用灵巧手”，中间为“停止并返回”，右侧为“保持停止”。注视左侧提交启用。
3. 等设备回执到达、页面变成“张开／停止并返回／闭合”，再选择动作。启用请求本身不等于动作已经发生。
4. 先张开，再闭合，最后重新张开。以实物和设备反馈共同判断完成情况。
5. 选择“停止并返回”，结束当前控制。切页后再次进入需要重新启用。

### 倒立摆平衡

1. 确认小车居中、摆杆按设备要求自然下垂且可自由摆动，人员离开运动范围，并能切断总电源。
2. 从“设备与方向”进入“倒立摆”，选择“平衡控制”。
3. 注视“启用倒立摆”，等待新鲜停止反馈、中立确认和启用成功。
4. 页面变为“启动平衡／停止并返回／停止平衡”后，选择“启动平衡”。
5. 初次复测先做短时观察，约 5 秒后主动停止并返回。成功立起、持续时间和实际停止要现场观察。

“停止平衡”沿用 STM32 原平衡停止命令；“停止并返回”撤销整个当前控制会话。结束演示或要停止全部输出时使用“停止并返回”。

### 倒立摆左右动作

从倒立摆入口选“左右短动作”，启用成功后出现“左转一圈／停止并返回／右转一圈”。这些是保留的菜单名称；已有现场验收确认的是预期方向移动及停用后停止，不是编码器量测出的固定一圈或固定距离。

先只触发一次，观察方向，及时停止并返回。左右页与平衡页之间切换会停用，需要重新启用。当前用户的 STM32 与电机共用供电，重启或烧录 S3 前倒立摆整体断电，灵巧手舵机断电，保留 S3 独立供电。

## 7. 图像处理与瞳孔定位

在主页按 PL_KEY0。每次按下并松开，进入下一个模式。

| 顺序 | 模式 | 视频源与观察方法 |
| --- | --- | --- |
| 1 | 原图 | OV5640；移动物体，确认新画面持续变化 |
| 2 | 霓虹轮廓 | OV5640；观察物体边缘叠加 |
| 3 | 彩色拖影 | OV5640；移动手或物体，观察衰减轨迹 |
| 4 | 运动分析 | OV5640；观察运动区域叠加 |
| 5 | 灰度 | OV5640；查看亮度细节 |
| 6 | 二值化 | OV5640；查看黑白分区 |
| 7 | 中值滤波 | OV5640；查看局部噪点处理 |
| 8 | Sobel 边缘 | OV5640；观察梯度边缘 |
| 9 | 直方图均衡 | OV5640；比较亮暗区域对比 |
| 10 | 瞳孔定位 | Tobii 真实灰度图；坐回原眼控位置并保持双眼可见 |

前九种模式保持 OV5640 视频源，PL 在连续像素流上处理。瞳孔定位切换到 Tobii，使用 PS OpenCV 找可靠候选、绘制椭圆与中心坐标；坐标单位是源图像像素，不是屏幕注视坐标。没有可靠候选时不画圈。

从图像模式进入脑电展示可按 PL_KEY1；从脑电展示按 PL_KEY0 返回图像原图模式。用 PS 按键或手机“返回主页”退出展示。图像模式中不转发注视动作来控制机构。

## 8. 脑电四页与音乐

在主页按 PL_KEY1，按以下顺序循环：疲劳分析 → 情绪分析 → 脑电音乐联动 → 音乐音频分析 → 疲劳分析。四页共享同一记录时间，切页不重启分析。

当前输入为 LEMON sub-010002 公开真实静息脑电记录：前 120 秒用于原算法基线流程，随后连续约 180 秒为展示段。原模型处理以 250 Hz 数据执行，波形显示为 50 Hz。进入展示不需要临时佩戴脑电帽；真实实时接入留待后续工程。四页不向执行机构发送脑电控制命令。

| 页面 | 应观察的内容 |
| --- | --- |
| 疲劳分析 | 八通道原始／滤波波形，统一微伏量程；时频能量；20 项特征；正常／轻度／严重与模型分数；8 秒窗口 |
| 情绪分析 | 同一波形时间轴；五频段六通道对数协方差热图；正向／中性／负向及原分类；12 秒窗口 |
| 脑电音乐联动 | 当前结果、选曲依据、确认状态、曲名和播放器状态 |
| 音乐音频分析 | 当前播放位置的左右声道波形、频谱、瀑布图、频段能量和电平 |

疲劳时频图只展示 50 Hz 显示支路能表达的 1-25 Hz；右侧五频段模型特征仍来自原 250 Hz 算法。情绪热图由原 105 项特征还原，颜色表示实际数值和正负，不表示置信度。质量不足、校准或失效时，以当前状态提示为准，不沿用旧结论。

### 音乐何时开始和停止

首次进入第三页后才启用选曲。正向对应明快，中性对应平稳，负向对应舒缓；严重疲劳优先舒缓。需要连续两次不同实际推理窗口确认同一选择，每首至少保持 20 秒，换曲约 1 秒淡出／淡入。

四页内切换后音乐可以继续。数据失效超过 3 秒时淡出停止；退出到主页也停止。三首本地器乐各约 48 秒，播完后等待后续换组；当前版本不会仅为保持有声音而自动循环同一首。

电脑浏览器需要点击“播放音乐”授权声音；板端使用原音频通路。电脑音频分析采用 PS 数值参考，板端新增 1024 点 PL FFT。实际 HDMI 听音与播放延迟在板端另验。

### 记录结束与重新播放

约三分钟展示结束后，撤销旧结果。板端退出展示再按 PL_KEY1 重新进入，即可从头播放；电脑点击“重新开始”。板端也可用包内 select_signal_source.py 提交本地重播请求，它不修改采集和执行端。

## 9. 表达、视频与手机操作

眼控主页中间进入“交流表达”，按屏幕句子选择原语音素材；右侧进入“多媒体”，按原菜单进入视频或音乐。视频中央为观看区，左侧进入翻页，右侧进入评价。翻页页为“上一条／返回／下一条”，评价页为“好／返回／厌倦”。各次选择仍要换区解锁。

手机视频库可按全部、点赞收藏和厌倦记录筛选。收藏标记保存在板端；“保存到手机”需要实际下载并由手机确认。手机观看读取所选文件，默认静音，不是 HDMI 的实时镜像。

上传使用普通 MP4，原界面上限 512 MB。选择文件、上传并校验，通过后按视频库流程准备显示缓存；刚上传不等于已经完成播放准备。音量滑条控制软件数字音量，显示器本身音量另行调整。原媒体素材继续使用 SD 卡目录，新包未要求删除旧视频、评分或密钥。

首次只演示本文主线时，保留原方向/SSVEP、采集设置、肌电和 MPU 的现有配置。这些入口不代替眼控设备页面，也不把记录分析结果接到电机输出。

| 1:15-2:00 | 倒立摆启用，启动平衡，短时观察后停止并返回 |

## 11. 正常结束与断电

1. 在设备页选择“停止并返回”，确认灵巧手和倒立摆停用；动作异常时直接使用可控的机构总电源。

3. 在手机点击“停止显示并恢复 PL”，等待本次会话完成退出。

## 13. 故障排查

按“最后正常的环节→第一个异常的环节”检查。每次只改一个因素。

| 现象 | 先检查什么 | 下一步 |
| --- | --- | --- |
| 电脑 9130 打不开 | 终端是否仍运行、依赖是否齐全、端口是否被已有服务占用 | 启动本地预览；已有服务则直接使用 |
| 手机打不开页面 | 是否加入 Z15 热点，IP、端口、原访问码是否正确 | 使用板端局域网链接；不要用 127.0.0.1 |
| 控制台红字或停止无回执 | 是否只打开了电脑预览，板端服务是否运行，网络是否断开 | 保持机构停止，恢复服务后重新启用 |
| HDMI 黑屏 | 显示器输入源、电源、HDMI 线及本次显示日志 | 从原控制台恢复主页；避免再加载一套 overlay |
| PL 键没有新版页面 | 是否已部署 r2、是否处于标定保护、是否按错 PS 键 | 退出标定并核对版本；全部松键后单次按下 |
| 眼控无法选择 | 双眼有效、标定完成、阅读保护结束、上次选择后是否换区 | 按原流程重新检查，不靠连续盯同一区重触发 |
| 启用成功但机构不动 | 启用后是否又选了动作，是否有新鲜设备就绪回报 | 先测试停止回执，再单次动作；不要重复发送启动 |
| 倒立摆蓝牙未就绪 | S3 Wi-Fi/TCP、BLE、STM32 状态分别是否正常 | 先确认供电；灯亮不等于 STM32 已回报 |
| 蓝牙灯常亮但数据不通 | 可能已被其他主机占用，也可能下游串口未通 | 断开电脑旧 BLE 测试连接，检查交叉接线和共地 |
| S3 反复复位 | 独立电源、USB 接入后的供电状态 | 先解决供电；机构断电后再调试重启 |
| 瞳孔页没有圈 | 是否已切到 Tobii、是否遮挡、双眼是否可见 | 调整位置，等待可靠候选；不改原眼控标定 |
| 疲劳暂时没有结果 | 当前窗口、质量或校准状态 | 等待实际有效结果；不要把热图颜色当分类 |
| 音乐没有声音 | 是否进入第三页、是否完成两次确认；电脑是否允许播放 | 检查播放器、数字音量和显示器音量 |
| 音乐播完不继续 | 当前曲目约 48 秒，是否有新的换组结果 | 按设计等待后续换组；需要整段重演时重新开始 |
| 记录结束、波形清空 | 是否已经到约三分钟末尾 | 退出再进入或点击重新开始 |
| 安装源文件或摘要不匹配 | 是否残留旧扩展或安装后改动 | 核对实际备份和日志，严格回退后重试 |

历史配置中 S3 地址曾为 192.168.50.45:9000，只能作为定位线索，现场以 S3 当前网络信息及 eye_devices.json 为准。普通使用不需要重新配置 C3 热点，也不需要电脑以太网共享。
