# 我们意念合一 EEG demonstration
<!-- impeccable:product-schema 1 -->
## Platform
web and local HDMI
## Stack
Existing Python HTTP runtime with local HTML/CSS/JavaScript, Canvas and SVG. No external network assets.
## Users
Competition judges watching a computer projection or recorded live demonstration; presenter may open it on a phone.
## Product Purpose
Show real eight-channel EEG processing from acquisition and filtering to features and fatigue/emotion results.
## Operating Context
Z15 ARM, fixed cap F3/F4/C3/C4/T7/T8/O1/O2, 250Hz acquisition. Read-only demonstration alongside existing eye/actuator controls. Full-screen recording and phone compatibility.
## Capabilities and Constraints
Approved warm ivory and champagne-gold presentation across all current surfaces. Fatigue 8-second window, emotion 12-second window. Preserve models, original protocol and calibration. No synthetic confidence or live-looking results without current data. Bundled LEMON real recording is the default presentation input; future live integration is outside this release. record/import/export up to ten minutes in browser. LEMON public records and local licensed instrumental tracks are bundled.
## Brand Commitments
Public name 我们意念合一. Ivory and champagne-gold surfaces, dark brown CJK text, sparse semantic colors, actual recorded waveform and processing progress.
## Evidence on Hand
October 17 archive and eye_c3 delivery, latest recovered runtime, real model source and weights. Host tests available; hardware currently untested for the new integration.
## Product Principles
Real data drives visible motion; processing state remains explainable; replay never controls hardware; existing controls remain accessible; faults clear stale results.
