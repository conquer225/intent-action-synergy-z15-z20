# OV5640 与红外成像路线评估

日期：2026-09-25。用户要求先分析，未决定更换相机。本记录不是采购定案，也不是已完成移植。

## 当前判断

不能因背光照片或当前算法失败就认定 OV5640 不可用。第一阶段是固定头位、双眼屏幕三区域识别，可以先评估虹膜暗区相对眼白/眼角的位置，不必先获得精确瞳孔轮廓。前提是目标使用距离下拍到足够清晰的眼部像素。当前固件采集 640×480；电脑显示的快照实际为 320×240 放大，画面放大不会增加细节。

保留 OV5640 时，先改善正面漫射照明、背景、焦点及镜头视场，检查原始眼部图像，再改候选筛选及拒识。改善算法不能恢复拍摄时已经缺失的细节。当前正点原子模组是否含红外截止滤片未核对，不能承诺加红外灯就能变成红外眼动相机；若改红外，必须确认整个镜头/滤片/传感器链路的透过和响应。

## 本日新增厂商证据

来源：[奥唯思 VS-SC130GS 产品页](https://www.szovs.com/cmos-camera/987793)，通过浏览器读取正文及页面内嵌 SC130GS 数据手册第 2 页。

- 模组页：黑白、全局曝光，接口为 MIPI 4 lane 与 DVP 10 bit，标配 M12 / 3.6 mm 镜头。另提供黑白和彩色硬件资料链接，选购时须确认版本。
- 芯片手册：支持 8/10 bit DVP，I/O 电源 DOVDD 1.8–3.3 V；这些是芯片能力，不代表所购模组开放全部模式，也不等于模组外部电源规格。
- 页面高帧率示例标注为 MIPI；不可据此声称在 Z15 P2 DVP 上可达到相同帧率。
- 页面提供 Xilinx 7A100T / Zynq7020 MIPI 方案，不代表现有 Z15 P2 有可直接使用的相同接口或工程。

本项目 Z15 现有 FPGA 摄像头数据和同步引脚按 1.8 V 约束，SCCB 使用 3.3 V 引脚，现有连接依赖底板电路；新模组须核对完整路径。当前 OV5640 采集是 8 位总线分两拍接收 RGB565，不等于新相机的单色像素格式。

## 红外路线物料与条件

| 项目 | 条件与用途 |
| --- | --- |
| 黑白相机模组 | VS-SC130GS 具体版本，要求模组原理图、引脚表、供电、时钟和 DVP 配置例程；优先评估 8 位 DVP 模式与现有通路适配 |
| 近红外适用镜头 | 在实际屏幕使用距离下同时拍清双眼；原配 3.6 mm 不预先认定适用 |
| 窄带滤片及固定件 | 与 LED 波段匹配，例如使用 850 nm 光源须配相应通带；不能仍被原有 IR-cut 阻断 |
| 红外照明组件 | 可调亮度、安装位置固定；需掌握使用距离、光学输出及人眼安全依据，不能按肉眼不亮判断安全 |
| 恒流驱动和电源 | FPGA 若控制 PWM/使能，应驱动灯的驱动器；灯电流不能直接由 FPGA I/O 供给 |
| 相机转接板/排线 | 模组至 Z15 的针脚重排、供电和必要电平转换；是否能用 P2 取决于所购版本，不能直接按 OV5640 插法连接 |
| 屏幕固定支架 | 固定相机与光源的位置和角度，减少每次演示重调 |

若走 10 位 DVP，需确定全部数据脚如何接入，或根据厂家资料设计明确的量化/截位方案，不能随意丢两根线。若走 MIPI，则另需适配板、电气接收及 CSI-2 解码，不是换排线能完成。

## 程序改动

相机 ID 和寄存器初始化、供电/复位/输入时钟时序、单色 8/10 位解包、曝光/增益控制、约束与时序都要重新适配。后续加入候选亮斑分组、暗瞳范围搜索、大小形状和局部对比检查、反光及背景拒识。亮斑/暗瞳的相对位置取决于光源与镜头几何，不能仅抄阈值。

现有 HDMI、串口和三点校准框架可以作为复用基础。瞳孔位置与屏幕区域之间仍需校准；全局快门不自动解决戴眼镜反光、头动或精确视线映射。未修改固件、执行新构建或完成新相机实测。

## 推进依据

优先对当前 OV5640 在固定坐姿和改善照明下的原始眼部帧做可用性评估。若能分清眼白和虹膜且左右注视变化可测，继续算法验证；若始终缺乏所需细节，再调整镜头或切换受控红外成像。红外路线有助于稳定特征，但需成像、驱动和算法一起改，不能承诺购买相机即复现参考效果。

## 用户现有双目板：AN5642 高度吻合候选

2026-09-25 根据用户提供的正反面照片，与 [ALINX AN5642 官方产品页](https://www.alinx.com/detail/476) 的正面和背面照片逐项比对：黑色 PCB 轮廓、接口伸出部分、四个安装孔、两处镜座圆形丝印、J3 双排弯角母座、U2/U3 元件组以及中央 X3 晶振布局高度吻合。现阶段可称为“很可能是 AN5642 或同 PCB 方案模块”；未从实物铭牌或芯片 ID 确认厂家、版本和传感器身份。

官网列出的 AN5642 规格为两颗 OV5640、每路 500 万像素、40 针 DVP 接口、M12 / 3.6 mm 镜头、手动对焦、双镜头间距 40 mm，含电源电路和时钟。网页小标题写作“OV5642 双目摄像头”，但正文和感光芯片表格均写两颗 OV5640；不要将模块型号 AN5642 误读为传感器 OV5642。

- [官网背面照片](https://www.alinx.com/upload/image/20241231/AN5642_20.jpg)

接口图标有两路 CMOS 数据/同步/控制信号及 +5V、D3V3、GND。它不是现有 P2 OV5640 模块的直接替换件；供电用途、I/O 电平及针序必须结合完整原理图核实后才能设计转接。当前 bitstream 只采集一路图像，在这一帧中分析两只人眼，尚无双摄采集或立体算法。可以在身份和接口确认后先评估一个通道，不必立即实现双路。

换用这块板的可能收益来自镜头、对焦和视场是否更适合目标距离，不来自“双目”名称本身。官网规格不能作为实物红外透过能力或瞳孔图像质量的证据，尚无该板实拍评测。

用户明确当前可接受固定眼框，因此框外背景误检不作为第一阶段主要阻碍。框外像素不直接参与 ROI 特征统计，但全画面曝光可能间接受背景影响；框内镜框、眼睑和阴影仍可能混入暗区。不能提前断言调阈值一定无效，也不能凭“眼有效”判定成功；应检查同一坐姿下左、中、右注视的特征是否稳定且可区分，并通过重复实际注视验证。

## 红外选型与其他可行路线

用户继续询问红外选型和替代可能性，尚未授权采购或确定改用某一方案。当前任务仍是屏幕上方安装相机、固定头位、左中右分类；预算、屏幕尺寸和工作距离未确认，不给出器件报价、交付工期或识别率承诺。

红外指近红外反射成像，不是热成像。对于当前缓慢注视分类，全局快门不是必要条件；曝光时间、有效眼部像素、对焦、动态范围和反光处理同样需要验证。VS-SC130GS 是已有官方资料与参考作品的候选，但具体黑白版本、DVP 是否实际引出、针序、电平与寄存器表仍须核实。不能因 MIPI 高帧率宣传而推断 DVP 性能。

| 路线 | 首个可检查结果 | 成本与主要限制 |
| --- | --- | --- |
| 现有 OV5640，先改照明/焦点/框选 | 同一位置拍出的原始眼图能分清虹膜和眼白 | 硬件投入低；若眼部细节不足，仅调阈值不能补回 |
| 现有 OV5640，改眼部检测算法 | 在独立录制的实际图像上比较梯度、连通区域、轮廓或个体分类 | 增加软件验证和后续 RTL/PS 工作；不能直接从清楚截图推导真实识别率 |
| 明确支持近红外的 OV5640 模组 | 配套镜头/滤片/照明后获得原始近红外眼图 | 可复用部分传感器经验；原装模组 IR-cut 未知，不默认允许拆滤片或仅加灯 |
| 黑白 DVP 相机配近红外光学链路 | 目标距离下稳定瞳孔图像，然后打通 Z15 单路采集 | 新增模组、镜头、滤片、灯、驱动、电源、转接和寄存器适配；SC130GS 为已有证据候选 |
| USB 黑白近红外相机先接电脑 | 快速验证成像、瞳孔候选和屏幕校准 | USB 不能直接接入当前 P2/PL 设计；若最终用 PS USB，需要另建主机软件和图像通路，若改 DVP 则需重新验证成像差异 |
| 现有疑似 AN5642 双目板 | 接口核实后，先比较一路在相同距离的眼部图像 | 两颗 OV5640 不自动改善瞳孔对比；双路增加接口、存储和同步工作，现阶段无需先做立体视觉 |
| 可见光相机加眼部关键点/小模型 | 使用真实 OV5640 数据，在分段验证集上输出三区域和拒识 | 已有论文支持一般可行性；当前 Z15 部署资源、数据量、个体差异未验证 |
| 近眼佩戴式相机 | 近距离稳定拍眼，另行建立与屏幕的关系 | 增加佩戴和场景/头姿标定，改变屏幕上方单相机场景 |
| 成品眼动仪 | 作为对照记录屏幕注视 | 采购及接口成本待查，核心识别可能由成品完成，不能当作自主 FPGA 识别成果；参赛适用性需核对规则 |
| EOG 眼电或头姿替代 | 输出粗方向/交互命令 | 眼电需电极、放大和漂移处理；头姿不能代表纯眼球转动，均属于需求变更而非现有相机直接替代 |
| 保留当前原型、暂停采购 | 维持出图/通信/参数设置能力并如实标注未完成眼控 | 不新增硬件投入，也不会自行解决识别失败 |

采购规格应要求：明确近红外响应和 IR-cut 状态，实际模组原理图与逻辑电平，DVP 输出模式及帧率，曝光/增益可控制，镜头覆盖实际距离下双眼，滤片与照明波段匹配，提供戴眼镜条件下未叠加算法的原始样图。850 nm 可作为有参考作品和论文依据的起点；940 nm 需重新核对传感器响应、曝光和光源输出，不能仅按更不可见判断优劣或安全。

算法也需随光学方案改变：当前明暗质心法的亮区设计意图是眼白，不可直接把近红外角膜反光点当作同一种参考。暗瞳候选/轮廓筛选、可选角膜反光参考、屏幕校准和无效状态处理均需实现与实测。近红外也会受到镜片反光、眨眼、日光近红外及头动影响。

可组合的验证顺序为：先用少量原始帧区分成像失败与算法失败，再决定继续 OV5640 或用借用/样机验证红外；电脑上先验证实际相机图像，再移植已验证算法到 Z15。切换相机后必须重复验证，不能用另一台 USB 相机的效果代替目标 DVP 相机的结果。当前串口每张快照约 7 秒，只适合少量静态样本；连续采集另需数据通路。
