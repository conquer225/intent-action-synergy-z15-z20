# 检查瞳孔与眼白灰度

这是电脑工具的新增检查功能，不需要重新下载 bitstream。读到的是 FPGA 发出的 320×240 静态灰度快照，不是手机拍屏照片或红蓝覆盖颜色。该快照来自 VGA 偶数行列，保留所采样像素值，但不能代替完整 640×480 实时检测的所有统计量。

## 点击顺序

1. 关闭旧的电脑设置窗口，双击 `tools/start_screen_monitor.bat`，或运行 `python tools/screen_monitor.py`。队友可解压单独的 `Z15_Gray_Inspection_PC.zip`，使用其中同名启动文件。
   首次使用且未安装依赖时，在解压目录运行 `python -m pip install -r tools/requirements.txt`。需要带 tkinter 的 Python，与原设置工具相同。
2. 选择 PL UART 的 COM 口，点击“连接”。处于校准阶段时，先点“返回预览 / 重新设置”。
3. 保持正常坐姿，看 HDMI 中间区域；让队友点击“取图（约 7 秒）”，直到图像出现。一个人测试时先发起取图再看目标不能保证冻结时刻的注视方向，此时只检查成像与灰度。
4. 点击顶栏“检查灰度 / 保存原图”。新窗口显示无红蓝覆盖的原图，不要求双眼有效，也不要求先应用阈值。
5. 鼠标移到眼部，右侧出现局部放大图、当前像素灰度、附近 3×3 的范围和中位数。0 最黑，255 最亮。移动鼠标不取新帧，局部放大也不会增加细节。
6. 下拉选择“眼1 暗部”，在画面左边那只眼可辨认的瞳孔/虹膜内部单击 3–5 个不同位置；选择“眼1 眼白”，在两侧可辨认的眼白内部单击 3–5 个位置。眼2同样操作。避开边界、眼睑、睫毛、镜框和镜片反光；无法分辨的位置不要强行标成眼白。这里的类别是人工标注，工具没有自动识别人眼。
7. 点击“保存原图和取样”。弹窗给出保存路径，在工程的 `local/eye_captures/日期时间_随机后缀/` 下，包含 `raw.png` 与 `samples.json`。把两份文件一起交给分析者，不要只拍显示器。图像仅保存在本机，不加入源码发布包。

重新取图后，关闭旧检查窗口，再点“检查灰度 / 保存原图”。旧检查窗口始终保留打开时那一帧，避免取样中途换帧。画面左边是眼1、右边是眼2，不按人的解剖左右命名。

## 如何读结果

下面都是示例，不是本次实测：

- 暗部多个点约 20–30、眼白约 65–85：存在可尝试分割的灰度间隔。原来的亮阈值 140 会漏掉这些眼白。仍需检查眼框内其他像素及左中右不同注视图。
- 暗部约 35–50、眼白约 45–60：数值重叠，单一阈值很难把两类完整分开，可以评估局部对比、轮廓或改善成像。不能仅凭范围重叠认定必须更换相机。
- 几个标记“眼白”的点来自镜片反光：再亮也不是有效眼白证据，需要重新标注。

附近 3×3 中位数用于查看局部波动，靠近边界时会混入其他组织，不能代替单像素值或人工确认。几处点击不能代表整个眼框的分布，也不能直接判定 FPGA 必然通过。

当前硬件限制仍是 `dark >= 8`、`bright >= dark + 16`、`bright <= 248`。本次检查不自动改变阈值、不放开校准按钮，也不改现有固件。PNG 保存的是原始取样灰度，没有覆盖色、标记、放大或自动增强。JSON 中设置项是打开检查窗口时的编辑值及确认状态，不能当作快照冻结瞬间的硬件配置。
