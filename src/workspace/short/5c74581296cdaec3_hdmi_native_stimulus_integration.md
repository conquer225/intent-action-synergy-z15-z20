## 接入内容

- `native_scan.c` 原生线程处理提前备帧、变化行带缓存同步与逐扫描锁存。
  仅该线程请求 CPU1 / SCHED_RR 优先级 1，每周期 CPU 预算仍为 8 ms。
  错过单一扫描、DMA 异常、锁存不符或晚回执均停止；未放宽原 ScanEvidence 门槛。
- 发布回执用 release/acquire 原子计数；消费者只读取不可变的已接受记录，
  不把正在写或失败的记录当成已完成扫描。
- 进入刺激前仅初始化两个非活动缓冲，旧菜单所在缓冲在解除扫描占用后才初始化。
  活动缓冲不允许复制；回收前必须完成原生线程 join。
- Python 普通线程批量传回最多 8 条回执；页面/会话身份、网络时延和旧结果撤销保持。
  原生线程独立核查 350 ms 回执保活，Python 卡住时也不继续长期更新刺激。
- 选择频率以原子变量改变相应角块的边框/选中颜色，不输入期望标签、不更改相位表。
  未选中时四个块外观一致；角块以外区域保持固定。
- 换页、警示、手机强制停止和会话结束会取消扫描，再恢复普通页面缓冲所有权。
  停止/join 失败时保留映射及 CMA 缓冲，禁止继续渲染或释放正在使用的缓冲。
- 手机候选入口必须带原生库路径与 SHA256，未准备好时拒绝启动恢复定时器/播放器。
  正式入口默认不开启该候选。
- 15 秒无新可信方向退出、过期方向撤销和轮椅禁用沿用原控制器。
