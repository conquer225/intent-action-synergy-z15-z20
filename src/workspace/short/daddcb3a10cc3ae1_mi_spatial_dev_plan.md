# 运动想象：因果滤波与空间解码开发对照（2026-10-01）

固定帽位 `F3,F4,C3,C4,T7,T8,O1,O2`，不佩戴、不修改正式版或质量门限。此前功率模型和两频带对数协方差未通过离线晋升门槛；本轮只做一次有界的空间解码对照，不宣称创新。

假设：空间滤波能提取简单通道功率未捕获的左右手差异；若完全跨人的开发均值仍低于0.60，而且按后续轮次评估的个人校准均值也低于0.65，则这一轮停止，不继续更换分类器或接入正式服务。

数据：复用已按官方SHA-256核验的EEGMMIDB左右手**想象**第4/8/12轮，只读取S001–S089。S090–S109此前已暴露，不读取、不称为新盲测。各EDF的采样率、通道名称、提示和文件哈希留存；不剔除弱受试者。

处理：只选固定八路，依据实际128/160Hz采样率，用单向FIR `upfirdn` 转到250Hz，不补偿约62.5/78.125ms群延迟、不访问未来采样；完整记录运行既有 `CausalEEGFilter`，再连续四阶因果频带滤波。以提示后1–4秒的3秒窗口计算逐频带8×8协方差，减去窗口均值，以矩阵迹归一。所有本轮模型用相同记录、窗口与协方差。与旧0.5–3.5秒/中心化重采样的分数只能作历史参照，不能计算同流程算法提升。

固定四个模型，不调参数：

1. C3/C4的8–12、18–26Hz对数方差＋收缩LDA。
2. 固定八路的同两频带对数方差＋收缩LDA。
3. 8–30Hz、四个CSP分量＋收缩LDA。
4. 8–12、12–16、16–20、20–24、24–30Hz五频带、每带两个CSP分量＋收缩LDA。

CSP仅用训练标签拟合：逐类平均迹归一协方差，向单位阵收缩0.1，解 `R_left w = λ (R_left+R_right) w`，按 `abs(λ-0.5)` 选择分量。特征为投影方差的对数；标准化、LDA仅在相应训练样本拟合。引用MNE的CSP/轻量分类官方示例作为实现参照，但使用自己的明确左右手标签协议；不照搬示例第6/10/14轮的双手/双脚标签。

跨人：S001–S070拟合，S071–S089开发验证，每人balanced accuracy均值、macro-F1与受试者bootstrap95%区间；全部模型、逐试次与逐人结果保留。无测试者标签或无标签数据参与训练/适配。
