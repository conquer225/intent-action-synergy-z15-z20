# 独立 ESP32 手机眼控接口

本目录用于备用 ESP32 的手机控制工作，与 `wheelchair_ssvep` 分开。

## 已完成的备份阶段

2026-10-06 用户授权仅对 COM17 进行复位、芯片/Flash 只读检查、完整备份、
备份校验及恢复原应用运行。不授权写入/擦除 Flash 或修改 eFuse。

- 目标：备用 ESP32-S3，USB 序列标识 `28:84:85:60:CD:9C`。
- 不操作：轮椅 COM16、Z15 ARM 服务或 PL。
- 备份存于 `firmware_backups/`，检查日志和结果存于 `output/`。
- 完整 Flash 备份可能含网络凭据，不应提交 Git 或公开分享。
- 备份读取成功不等于恢复写回已测试；本次不测试写回。

此处记录的是早先只读备份的授权范围；随后独立 BLE 固件的授权与部署见下文。

## 当前授权：独立 BLE 鼠标

随后用户已明确授权仅替换 COM17 的固件，先验证华为手机手动翻页，之后再接眼控。
工程和操作说明见 `firmware/README.md`。使用已安装的官方 Arduino BLE/NimBLE 库，
不安装第三方鼠标库，不接眼控自动命令，不启动 Wi-Fi，也不操作轮椅、Z15 或 PL。
已仅写原 app0 分区；设备原固件备份不覆盖、不删除。

## 当前部署结果

2026-10-06 已在备用 COM17 部署 `guardianloop-eye-mouse-0.1.0`，蓝牙名
`GL-EyeMouse`。应用从 `0x10000` 写入 597,152 字节，写入摘要校验和独立
ROM 写后校验均通过；没有写 bootloader、分区表或整片擦除。

实际板上 `SELFTEST` 通过，电脑串口脚本的 11 项测试通过。部署结束时状态为未连接手机、
未启用控制、鼠标报文数 0，Wi-Fi 与电机 GPIO 均未启用；本轮未操作 COM16、Z15 或 PL。
部署记录：`output/com17_ble_mouse_deployment_20261006.json`。

随后用户已完成 `GL-EyeMouse` 配对，设备报告加密连接及 HID 通知订阅就绪。
单次 `NEXT` 滚轮指令未产生可见变化；单次 `MOVE_RIGHT` 后用户确认指针在屏幕中央出现；
单次 `SWIPE_UP` 后用户确认抖音切到下一条，单次 `SWIPE_DOWN` 后用户确认返回上一条。
每次动作后均收到 STOP 确认并核对未启用状态。
记录：`output/com17_manual_next_20261006.json`。

仅确认本手机、本次前台视频页的手动双向翻页；同方向重复稳定性、指针复位、眼控自动接入、
Z15 无线桥及原固件恢复写回均尚未验证。这不是已完成的眼控闭环。
