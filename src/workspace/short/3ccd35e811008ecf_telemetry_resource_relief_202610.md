# 遥测与 HDMI 资源竞争：缓存对照（2026-10-09）

后续待机 MI 减负与 CPU 角色分配的检查见
[MI_IDLE_RESOURCE_RELIEF_20261009.md](MI_IDLE_RESOURCE_RELIEF_20261009.md)。
后续帧进展采用计数发布时刻统计；本文保留当时按观察时刻计算的原始软件比值，
它们不能当作物理显示帧率。

## 当前结论

完整波形发布的重复编码确实消耗 CPU；已实现保留完整波形的增量 JSON 行缓存，
并完成板端正确性及 156 秒同场回放。但输入积压长尾和视频低谷仍存在，
整机实时性未通过。候选尚未替换正式发行版。

本轮不需要佩戴，没有打开真实 Cyton 串口做新实验、改变模型／通道／质量阈值、
重启正式采集、加载 PL、改写 SD 卡或驱动轮椅。既有显示会话只进入静音视频页，
测试后回到主页，用户控制的常开入口仍保留。

## 已确认与改动范围

原遥测每 0.5 秒发布一次，包含原始和滤波后的 625×8 样本，即 125 Hz 的 5 秒历史。
连续两次之间通常新增约 62／63 行，仍会完整复制、舍入和编码全部历史。
先在隔离回放中关闭遥测，常见延迟下降，但最坏长尾仍超过 1 秒；不能把遥测称为唯一根因。

- 新增 `pynq_guardianloop/telemetry_json.py`：只缓存数值波形的 JSON 行，
  用样本计数差和两组舍入后数组的重叠逐值比较确认可以复用。
  计数回退、形状变化、任一重叠数值变化时完整重建；非有限值仍报错。
  更新频率、125 Hz 采样标记、5 秒历史和全部八通道不变。
- 遥测工作进程持有该缓存。每次元数据、原提交时间、输入年龄、质量、
  校准进度、预测有效性和失效原因均重新编码；不复用旧预测或旧时间戳。
- `TelemetryWriter.submit` 的两组独立快照由 `asarray(...).copy()` 改为
  `array(..., copy=True)`，保留独立所有权。容量为 1 的非阻塞队列与故障可见性不变。
- 网页已有的响应字节缓存、过期判断和显示代码本轮没有修改。
  未通过修改刷新时间、删除波形或放宽过期阈值冒充性能提升。

代码保存在本地及板端隔离目录 `/home/xilinx/gl-prewear-compute-20261009-LcGhCQ/runtime`。
正式目录没有增加此模块。候选哈希在 `telemetry-candidate-hashes.json`。

## 验证结果

本地共 26 项测试，22 项通过、4 项依赖 Linux 的测试跳过。
板端合并回归 39 项全部通过，65.305 秒、退出码 0，覆盖：

- 缓存／完整 JSON 解码后波形与元数据一致；计数跳跃、窗口增长、重置、舍入边界；
- 非有限值拒绝、输入快照独立、原子发布、时间戳不被缓存刷新；
- 显示队列满与工作进程故障可见，旧输入不变成有效预测；
- 校准保持、断流后撤销、进程重启后重新积累新鲜数据。

板端 24 次交错微基准使用生成波形、私有 tmpfs 文件，完整发布 CPU 中位数
63.853 ms，缓存版 23.386 ms；墙钟中位数 64.595 → 23.428 ms。
连续 625 行中复用 562 行，解码后的完整载荷逐项相等。
这是单次波形发布成本，不是整机或光学帧率，也不是识别准确率。

## 156 秒完整记录对照

两组均与同一个既有 HDMI 静音 20 fps 缓存视频并行，视频页策略使 SEED／SSVEP 候选暂停，
不自动发起 MI 试次。正式采集保持运行，因此是附加隔离回放压力检查，
不是新佩戴实验或正式串口链路验收。两组都不启用阶段探针、不重复输入，
处理 39,000/39,000 包，退出正常，无监测错误和剩余子进程。

第 7 组仅为“关闭波形发布”的诊断，不能部署：

- 输入年龄 p95 182.584 ms，最大 1,056.182 ms；主处理最坏 1,027.139 ms。
- 主进程 CPU 60.198 秒，子进程累计 82.719 秒。
- 情绪 8 个预测、疲劳 5 个正常输出，仍有 3 次积压失效。
- 显示快照的加权软件帧进展约 17.46 fps，最低比值约 5.99 fps。

第 8 组保留完整波形，启用缓存：

- 输入年龄 p95 248.617 ms，最大 831.243 ms；主处理最坏 607.687 ms。
- 主进程 CPU 69.617 秒，子进程累计 95.118 秒。
- 情绪 5 个预测、疲劳 4 个正常输出；另有校准及质量拒绝，不能说全部时段可用。
- 4 次积压失效；最后快照记录 5 次流恢复（包含记录自身的序号缺口）、312 个陈旧包弃用。
  两次校准完成后的积压失效均保留 15/15 校准和 `calibration_retained=true`。
- 生产者 156.001 秒完成，最长迟到约 19.7 ms，没有超过 100 ms 的生产批次迟到。
- 220 秒只读显示观测含回放启动／收尾，203 个快照、202 个可比较区间；
  加权软件帧进展约 16.28 fps，最低比值约 4.76 fps，71 个区间低于 16 fps。
  它不是逐扫描或光学测量，不能判为物理显示稳定达到 16 fps。

上轮第 6 组完整编码的输入年龄 p95 292.992 ms、最大 1,121.491 ms。
本轮单次对照更低，但没有重复试验统计保证；不能承诺以后不会断流或低帧率。
各组接受窗口数不同，不按窗口序号强行宣称模型结果相同，更不能将预测数量当作准确率。
