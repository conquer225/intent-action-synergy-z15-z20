# 固定八通道 SEED：跨人改进与部署候选（2026-09-26）

## 结论

固定 `F3,F4,C3,C4,T7,T8,O1,O2`，15人逐人留出，每人三个会话全部留在测试侧。
本轮找到的改进是：**用过去窗口的均值持续校正协方差对数特征，再用收缩LDA分类**。
相同测试窗口下，平均跨人平衡准确率从 **59.5601% 到 67.5760%**，增加8.0159个百分点。
15位受试者均有改善；描述性配对95%自助区间为+5.3756至+10.9998个百分点。

这不是70%的结果，不是用户佩戴准确率，也不是独立确认研究。此前多次使用同一SEED人群挑选方法，
本轮的区间不能修复整个探索过程的选择偏差。SEED任务是影片诱发的正/中/负三分类，与GAMEEMO游戏条件、
DEAP效价/唤醒度和疲劳标签不同，不能合并比较。板端服务、模型、bitstream均未修改。

## 冻结条件和数据流

- 数据：`D:\ican\datasets\SEED\SEED\Preprocessed_EEG`，45个会话、15人。
- 通道零基索引：`7,11,25,29,23,31,58,60`；绝不替换成邻近电极。
- 复用初始实验的哈希验证特征：200Hz，12秒无重叠窗口，每试次滤波热身2秒。
- 频带：1–4、4–8、8–14、14–31、31–45Hz；每频带8×8正定协方差，矩阵对数上三角，非对角乘sqrt(2)，共180维。
- 初始12330窗口；每会话前5窗口用于无标签校准，训练和测试均排除相同窗口，剩12105窗口。
- 第一段影片是正类，不可称作中性静息校准；校准共60秒有效信号，另有滤波热身。
- 原始、前缀、持续适配都使用相同人划分。StandardScaler只拟合训练人，LDA等先验、自动收缩。
- SEED原始预处理本身是离线产物；这里的“因果”限定为我们新增的过滤/特征适配步骤。

设x_t为当前180维特征，n为此前接纳窗口数，m为这些窗口的均值：

```text
前5个窗口：只初始化 m 和 n=5，不参与测试计分。
第6个起：
  z_t = x_t - m
  score = W @ z_t + b
  prediction = classes[argmax(score)]
  m = m + (x_t - m)/(n+1)
  n = n+1
```

先预测再更新，不访问未来窗口、目标标签、影片编号。记录结束后重置状态。
真实设备SQI拒绝时是否跳过更新尚未验证，不能宣称已有抗坏通道能力。

## 本轮全部结果

第一组使用初始全部12330窗口，原logcov-LDA为59.5642%：

- 原logcov + RBF SVM：57.74295%，未改善。
- 去每窗口/频带对数尺度 + LDA：57.94172%，未改善。
- 去尺度 + RBF SVM：55.95595%，未改善。

第二组使用完全相同12105窗口，原LDA为59.56007%：

- 固定前60秒均值校正：63.10107%；提升3.541个百分点，通过本组探索门槛。
- 前60秒协方差白化（EA式机制）：62.42472%；配对区间跨零，未通过。
- 整会话均值校正：69.52116%；**读取未来数据，仅诊断，禁止作为实时成绩**。

第三组与固定前缀63.10107%比较：

- 累计历史均值校正：67.57597%；提高4.47490个百分点；本组三比较校正区间+2.44450至+6.68559个百分点。
- 指数均值alpha=0.04：66.38991%；也改善，但未优于累计均值。
- 固定前缀 + RBF：62.38511%；未改善。

每组在运行前保存protocol；探索门槛为至少+2个百分点且该组多比较校正的受试者bootstrap区间下界大于0。
这不是整个研究历程的全局多重选择校正。确定性线性/SVM算法不以重复相同随机种子冒充重复验证。

## 影片顺序压力测试

SEED影片顺序跨人相同，因此额外固定算法、在每人每会话独立打乱整段影片顺序，保留片内窗口先后，
三种种子均重新按最初5窗口校准，原模型也排除同一窗口。每个种子仍是15人LOSO。

- 20260926：原模型59.85487%，累计校正66.16247%。
- 20260927：原模型59.55452%，累计校正66.70471%。
- 20260928：原模型59.48356%，累计校正65.68453%。

种子平均的逐人配对提升区间为+4.11395至+9.28022个百分点，三次均改善。
这说明改进不完全依赖原来的统一影片顺序；但重新排序不等于新的自然采集，不能消除所有刺激/记录混杂。

## 论文和作者代码核查

1. [Stratified Normalization](https://www.frontiersin.org/journals/neuroscience/articles/10.3389/fnins.2021.626277/full)
   强调按人、按会话归一化。它的归一化范围和我们的即时无未来推理不同；本轮借鉴“去记录间偏移”的机制，
   不是原网络复现，也不照搬其报道分数。
2. [MS-MDA作者代码](https://github.com/VoiceBeer/MS-MDA/blob/main/msmdaer.py)：
   train读取target_data做适配；周期调用test，并返回观测到的最大target正确数。
   因而直接用该代码返回值与严格最终未知目标测试分数比较不公平。此处是对所查看代码版本的审计，不是断言所有论文结果均无效。
3. [Euclidean Alignment](https://arxiv.org/abs/1808.05464)：
   使用参考协方差白化，原研究针对MI/ERP，不能把其任务分数迁移到SEED。
   我们在前60秒参考上的机制试验未通过改善门槛，保留负结果。

本轮证据支持“会话/受试者分布偏移值得处理”，不证明接触污染、滤波或电极位置没有问题，也不证明更深网络无用。
