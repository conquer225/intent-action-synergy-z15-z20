# 共享 RMS 候选的隔离 ARM 验证

2026-10-03，板测前声明；固定 `F3,F4,C3,C4,T7,T8,O1,O2`。

只检验上一轮冻结模型是否能在 Z15 ARM 上保持计算、质量门控与恢复行为，并跟上既定提示窗口负载。并不重训、评分识别准确率或证明用户想象方式有问题。

## 配套候选及比较

使用 `output/mi_rms_comparison_20261003/experimental_rms_eegnet.npz`，固定 `s01_seed42`，不择优选种子。其模型、共享 RMS 代码及隔离加载器必须匹配上一轮 SHA256。旧对照为 `output/mi_cued_delivery_20261002_final/experimental_eegnet.npz`。

两个模型都调用原 `CuedMISession`、连续 CAR/50 Hz/1–45/8–30 滤波、完整500样点窗口和物理单位硬质量检查。只在新模型加载器内部增加共享 RMS，不能归一化用于原始质量检查的波形。借用已有 recorded-only 验收的回放和断流恢复函数，不复制/更改正式流状态机。

## 输入与项目边界

- 新模型固定源拟合人中的前256个已有滤波窗口，复用先前NumPy/Torch验证的索引，不使用确认人或标签；正常幅值比较PC与ARM logits。
- 其中前16个窗口及7个已有真人窗口，检查预声明倍率 `1,1/8,1/32` 的输出一致性；不根据真人提示算准确率，也不选择模型。
- 156秒已验收台架记录 `output/accepted_bench_load_20260927/bench_input.npz`：39000样点，以50样点/200ms喂入；只读 `recorded` 和 `recorded_seq`，程序生成合成提示。台架不是左右手生理标签。
- PC和ARM分别对旧/新模型进行逻辑回放、源及真人探针、断流恢复。新模型另做156秒实际节拍回放。
- 单窗口旧/新完整推理交替测64对，各预热4次；另量共享RMS本身的耗时。不把内核耗时冒充传感器到网页端到端延迟。

## 预声明验收条件

- PC/ARM logits绝对误差≤1e-4且类别完全一致；连续滤波误差≤1e-6+1e-7×参考绝对值；有效样点掩码和全部离散流状态一致。
- 新模型倍率变化的类别一致，误差≤1e-4；平坦、非有限及错误形状输入拒绝，通道间功率比例保留。
- 台架回放预期13次完整推理、6次休息、末次不完整试次撤销、首50样点无效、EOF清空旧结果；不是13次正确识别。
- 新模型实际节拍：feed批处理p99<200ms，最大调度迟到<500ms，末10%相对首10%的中位迟到增加<50ms；原质量资格不放宽。
- 包序号缺口撤销结果、重置计数，未热身时拒绝复用、重热身和新窗口后恢复；陈旧数据/断连撤销结果。
- 正式目录/启动文件/服务文件哈希、两个服务PID及重启次数前后不变；源输入及测试源码不变。若服务自行重启也记为保全条件失败，不擅自重启或归因于算法。

不暂停服务，不访问串口、不操作PL/设备树/驱动/启动镜像、不安装依赖。只写由 `mktemp` 生成的独立用户测试目录。ARM进程采用nice10及单BLAS线程，超时TERM后5秒KILL；原服务始终保留。隔离文件保留用于追溯，不热切换、不永久部署。无须佩戴。

这是当前正式服务旁的隔离MI回放，不能声称生产全部任务在真实Cyton负载下已验收，也不会改变当前网页的模型。
