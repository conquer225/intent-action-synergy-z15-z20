# 独立 BLE 手机鼠标台架版

目标仅为备用 ESP32-S3 COM17，USB/MAC `28:84:85:60:CD:9C`。
本轮用户已授权替换该板固件。轮椅 COM16、Z15 和 PL 不在范围内。

## 功能与边界

- 广播名 `GL-EyeMouse`，产品身份 `guardianloop-eye-mouse-0.1.0`。
- 使用电脑已安装的 Arduino-ESP32 3.3.11 官方 BLE 库，不安装外部 BLE 鼠标库。
- 四字节报文：buttons、相对 X、相对 Y、垂直滚轮；Report ID 在 GATT 描述符中，不重复塞进报文。
- 仅 USB 本地手动指令；不启动 Wi-Fi，不初始化或写入电机 GPIO，不接眼控/脑电自动命令。
- 初始未启用；BLE 连接、配对认证、HID 通知订阅均就绪后，`ARM` 才启用 30 秒。
- 动作不排队、不循环；完成后冷却 1 秒。拖动正常时长约 500 ms，最长许可 1 秒。
- `STOP`、许可过期、蓝牙断连、HID suspend 或通知状态变化撤销动作和启用状态；重新连接不自动恢复动作。
- `NEXT/PREV` 分别发送滚轮 -1/+1；这是候选操作映射，不保证抖音实际响应或响应方向。
- `SWIPE_UP/SWIPE_DOWN` 在鼠标当前位置左键按住、相对移动、释放。使用前必须把指针放在视频内容中部。
- 不包含点赞、评论、关注、购买或支付功能。拖动可能被 App 理解为点击等操作，必须先人工监督验证。
- BLE 使用 Secure Connections bonding、Just Works，不具备 MITM 身份确认。手机配对须由用户在本机蓝牙设置完成。
- 电量服务显示固定 100% 占位，本板 USB 供电；没有电池电量测量。
- 发送通知不等于手机已执行；串口状态不会伪造手机动作反馈。

当前只是独立鼠标兼容性验证。眼控接入、无线指令鉴权与重复触发抑制属于后续步骤。
未来需由 Z15 直接发命令到 ESP32，电脑不作为最终运行桥梁。

## 构建

```powershell
& 'C:\Users\lenovo\AppData\Local\Programs\Arduino IDE\resources\app\lib\backend\resources\arduino-cli.exe' compile `
  --fqbn 'esp32:esp32:esp32s3:USBMode=hwcdc,CDCOnBoot=cdc,PSRAM=disabled,FlashMode=dio,FlashSize=8M,PartitionScheme=default_8MB' `
  --build-path 'D:\ican\codex_project\phone_eye_control\build\arduino_ble_mouse' `
  --build-property 'compiler.c.extra_flags=-Werror' `
  --build-property 'compiler.cpp.extra_flags=-Werror' `
  --warnings all `
  'D:\ican\codex_project\phone_eye_control\firmware\guardianloop_eye_mouse'
```

物理 Flash 为 16 MiB；原启动/应用头使用 DIO 80 MHz、8 MiB 声明，分区与官方
`default_8MB.csv` 一致。保持这套声明和分区，禁用 PSRAM。仅烧录新应用到
`0x10000`，不上传生成的 bootloader、partition、boot_app0 或 merged 文件。
原镜像及原 app0 保留，写回恢复尚未实测；不要无授权运行烧录或恢复操作。

## 检查和人工联调

源文件 `control_selftest.h` 与固件使用同一 `Controller`，覆盖未启用/未连接拒绝、
一次滚轮、冷却、两方向拖动/释放、STOP、启用过期、动作过期、重连不恢复、
计时器回绕、指针移动以及 HID 描述符 32-bit 长度。
固件启动先跑同一自测；失败时不启动 BLE。`SELFTEST` 可再次运行，不发送 HID 报文。
本机 MinGW 缺失 C++ 前端、WSL 没有 g++，因此不安装编译器，使用 ESP32 固件的实际运行自测。
`tests/test_mouse_control.cpp` 保留为有完整 C++ 编译器环境的离线测试入口。

用已有 Python/pyserial 运行（只核对 COM17 身份，不接受其他端口）：

```powershell
& '.\eeg_apps_z15\.venv-mi\Scripts\python.exe' '.\phone_eye_control\serial_control.py' --command STATUS
& '.\eeg_apps_z15\.venv-mi\Scripts\python.exe' '.\phone_eye_control\serial_control.py' --command SELFTEST
```

手机保持正常互联网连接，在设置→蓝牙配对 `GL-EyeMouse`。
用户确认已在抖音视频页、同意单次操作后，才可运行带 `--allow-action` 的手动动作：

```powershell
& '.\eeg_apps_z15\.venv-mi\Scripts\python.exe' '.\phone_eye_control\serial_control.py' --command SWIPE_UP --allow-action
```

手动脚本先核对身份/模式/就绪状态，启用后只发一次动作，等待结束并 STOP。
默认 `STATUS` 不发鼠标动作；没有常驻自动翻页程序。
