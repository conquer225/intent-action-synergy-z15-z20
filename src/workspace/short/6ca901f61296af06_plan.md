# Isolated matrix-moment PL candidate (2026-09-30)

This is an engineering experiment, not a production overlay change. The real
acquisition order remains `F3,F4,C3,C4,T7,T8,O1,O2`. The currently deployed
GAMEEMO covariance model selects `F3,F4,T7,T8,O1,O2` and has five separately
filtered bands. This candidate accelerates only the reusable moment reduction
of one six-channel band window: six sums and 21 unique entries of `X.T @ X`.
The ARM retains filtering, covariance normalization/regularization, symmetric
matrix logarithm, SVM inference, quality gating, and all control logic.

Hypothesis: for a sufficiently large accepted multi-task load, a streaming
fixed-point PL moment reduction plus transport is faster than ARM's same
reduction without changing downstream predictions. A faster isolated RTL core
is **not** sufficient evidence. An otherwise identical paced 80-second replay
must show at least 10% lower total CPU and p95 input age, meet existing
freshness limits, and preserve outputs; otherwise do not promote it. This is
an exploratory engineering threshold, not statistical significance.

Predeclared checks:

1. Compare quantized moments against floating-point covariance on existing
   recorded data, including overflow/rail detection and all five bands.
2. Simulate reset, start/end framing, stalls, and two consecutive windows.
3. Synthesize/route in an isolated Vivado 2025.2 project and report exact
   timing, LUT/FF/BRAM/DSP. No bitstream or board mutation at this stage.
4. Only if numerical and resource checks pass, measure real DMA transfer and
   paired ARM/PL end-to-end replay on Z15 before any production change.

The existing 80-second recorded trace is sometimes signal-gated. Identical
invalid states do not prove emotion accuracy or inference equivalence; this
experiment also needs direct feature/prediction comparisons on accepted
windows. Do not label offline replay as live Cyton input.
