# 统一 HDMI 与按页面调度：隔离工程记录

用户授权先改善显示/脑电资源竞争，再接真实输入；右手/休息模型重训留到以后。本轮静音，未触碰 ESP32、电机、开机配置、正式模型或新的 bitstream。

## 配置与边界

Z15 / XC7Z015CLG485-2，正式版 `guardianloop-fixed8-mobile-web-20261003` 48 个清单文件。固定 F3/F4/C3/C4/T7/T8/O1/O2、250 Hz。旧台架记录重复回放，不打开 Cyton 串口、不将记录中的标签作为真实意图或情绪准确率。

现有 `/home/xilinx/tobii_z15/overlay/eye_wifi.bit` 和 HWH 继续承担 HDMI/VDMA。显示进程获取原有两个锁；切页只换缓存画面，不重复下载 Overlay。结束先停止显示 DMA，再释放 CMA，回退正式 `guardianloop_pynq.bit`。独立定时器核对本次 PID/命令行；不改 SD 启动配置。

一个脚本会话依次覆盖主页、方向、速度、多媒体、视频、翻页、评价、表达、歌曲、主页。没有真实眼控事件、没有闪烁刺激、没有声卡输出；MI 的中性间隔仍是状态机接口而非训练出来的分类器。

## 实现

- `guardianloop_system/core.py` 复用既有眼动停留与 SSVEP 证据门控。GAMEEMO 的四种原始标签含义不改；boring/horror 可触发显式“模型估计”的心情参考/选歌提示，冷却 120 秒，不自动发声、不抢占方向页。
- `guardianloop_system/page_policy.py`：2 秒 monotonic 租约。保留主滤波、质量、情绪、疲劳和 MI；方向页启用 SSVEP，非主线 SEED 暂停。没有关闭主监测来伪装更高帧率。
- `pynq_guardianloop/page_scheduled_replay.py`：暂停可选消费者并停止其原始包 IPC；换页丢弃候选旧基线与频率，恢复重新热身。原主采集和原始包计数不改。
- `phone_video_upload/system_hdmi.py`：缓存中文背景、菜单和边框，视频只写中央区域，连续行 strip flush；独立守护执行未修改的正式运行约束检查，4 秒期限内未更新即拒绝继续。
- `frame_fitter.c`：整数最近邻缩放，颜色无变换。最新横版显示 384×216，坐标 448,245，落在中央列内。不是完整 720p 画质，不能混淆 HDMI 720p 扫描与视频细节。
- `run_system_stage.py`：只复制私有代码，校验源 hash 和正式 payload，有限回放、有限显示、独立回退与最终检查。相同输出目录保留，不覆盖失败结果。

## 初轮证据与纠正

`play-system-bee64c89-report.json`：十次脚本页面切换、只下载一次显示 Overlay；814 新视频帧/62.034 秒视频页，13.122 fps，最低完整秒 0 帧，未通过持续 16 fps。用户也观察到卡顿，并指出 640×360 区域跨出中央菜单边框。现已在隔离源码改为中央列内缩放。

初轮 300 秒回放消费 75000/75000 包，无报告错误、无剩余子进程；输入年龄 p95 2068.34 ms、最大 4433.76 ms。共同 51 个主输出窗口的情绪/SQI/疲劳发布值与旧正式参考逐项一致。不同运行时长/调度配置的统计不是严格单因素因果对照。

第二轮曾启用数组存储，但被复制的正式流类不支持 `storage` 参数，导致情绪候选被原主循环关闭。此轮已停止，未启动 HDMI，不能计作模型齐全的性能验收。已加入前置兼容检查，显式加载当前已验证的私有数组流源码；不覆盖正式 48 文件，也不替换 SVM 权重。板端五个流窗口与未修改的正式流特征逐位一致，最大误差 0。

板端等比例缩放、填充行保护、空指针拒绝、菜单 ROI 不越界和守护失败/超时测试通过。最终布局/资源联合回放及恢复结果以 `phone_video_upload/output/unified_hdmi_20261007/` 的后续报告为准；未通过部分不得描述为正式完成。

## 框内版本的联合回放

`play-system-87e96516` 配合 `eeg-page-final`：100.015 秒、十次脚本切页、一次显示 Overlay；1104 个新视频帧 / 62.016 秒视频页，平均 17.802 fps。中央 ROI 384×216 完全在框内，菜单/显示没有报告错误，DMA 停止、缓冲释放和正式 PL 恢复通过。

最低完整秒仍为 0 帧，不通过持续 16 fps。最长新画面间隔 1.723 秒；缓存等待 18 次。复制/flush p95 44.170 ms、锁存/扫描 p95 25.480 ms。虽然平均值比初轮高，不能隐藏这些停顿或把平均值描述为稳定流畅。

同场回放消费 75000/75000 包，输入年龄 p95 898.022 ms、最大 2100.180 ms，无报告错误/残留子进程。51 个共同主输出窗口仍逐项一致；MI 有 25 个计算候选、无 HTTP/适配错误，退出时旧结果撤销、线程结束；SSVEP 在方向页恢复计算，离开及最终关闭后失效；SEED 保持暂停。这是无标注的旧记录负载测试，不是分类准确率。

另有 `eeg-page-fitted-official` 无 HDMI 对照：75000 包完整处理，输入年龄 p95 201.732 ms、最大 1141.402 ms，51 个共同窗口一致。名称中的 official 仅表示模型权重/复制的发布载荷不改；该目录仍是私有候选，不代表已上线。

后续有限对照把既有 640×360 缓存预缩到中央显示的 384×216；显示像素与原逐帧缩放一致，不重复帧、不关掉情绪/疲劳/MI来提高数字。该缓存不等于任意竖版或旋转文件已获验证。

`play-system-6e1789e9` / `eeg-page-prescaled`：1210 个准备帧全部按显示像素核验，缓存 252654116 字节，两个 RAM 块共 7.594 MiB。62.033 秒显示 1174 新帧，平均 18.925 fps，缓存等待 0 次；复制/flush p95 3.415 ms、锁存/扫描 p95 20.571 ms。但最大新画面间隔仍 2.064 秒、最低完整秒 0，持续 16 fps 仍不通过。输入年龄 p95 370.204 ms、最大 1069.618 ms，75000 包完整处理，51 共同窗口一致、无报告错误/残留子进程。

该停顿不在复制/锁存计时内，不能继续直接归咎于缓存等待。已核对板上安装的 PYNQ getter：`PL.bitfile_name` 经 `Device.active_device.bitfile_name` 访问 `_client.bitfile_name`。下一有限对照把这项客户端查询放入原守护线程，保持原正式运行约束及 4 秒新鲜度期限；查询失败/超时仍终止显示。新增守护、状态写入、命令读取的耗时记录，作为定位依据，而不是预先断言已消除停顿。

`play-system-c215b7d3` / `eeg-page-owner-watch`：平均 19.397 fps，最低完整秒 4，仍未通过。新增计时抓到状态写盘最大 1228.805 ms；复制最大 42.690 ms、锁存最大 65.332 ms，守护检查最大 415.642 ms，命令读取最大 81.807 ms。不能将全部停顿说成 PL 查询；实测还存在显示主循环内的状态磁盘阻塞。

后续隔离版本将实时页面租约与状态写入 `/dev/shm/<私有目录名>-system-page.json` 和 `-player-status.json`。结束使内存租约失效，并将最终状态/报告保存到原私有目录；原始脑电与上传文件不迁移、不覆盖。2 秒页面租约和 4 秒守护期限不变，正式网页/采集服务和启动配置不动。`run_system_stage.py collect` 读取内存快照；正式服务并未接入该路径。

## 本轮收尾版本：内存状态

`play-system-994c7e21` / `eeg-page-ram-status`，同一显示所有者、十次脚本页面切换、一次显示 Overlay。100 秒会话内显示全部 1210 个准备帧，视频有效时段 60.731 秒，平均 **19.924 fps**；两个缓存块共 7.594 MiB，进程 CPU 约 17.88%。复制/flush p95 3.300 ms，锁存/扫描 p95 19.176 ms；状态写入最大降至 29.660 ms，守护检查最大 325.125 ms。

最大新画面间隔 344.908 ms。最低完整秒仍为 **14 帧**（视频第 2 个完整秒），其余完整秒 19–21 帧；缓存等待共 6 次。严格 `meets_16fps=false`，不能描述为全程稳定 16 fps。启动预取是下一项有限优化候选，尚未以新试验验证；这轮到此保留证据，不继续无休止调参，也不升级为正式上线版本。

本轮降低视频细节到中央 ROI 的现有尺寸，保留主滤波/质量、情绪/疲劳与 MI；SEED 继续暂停、方向页面才恢复 SSVEP。没有改模型标签、没有声卡输出、没有真实脑电/眼控控制、没有实体方向或速度命令。显示 DMA 停止、CMA 缓冲释放和正式 PL 恢复均已通过。

最终回放消费 75000/75000 包，输入年龄 p95 302.243 ms、最大 2055.144 ms；不能说没有任何短时排队。51 个共同主窗口与未修改的原参考逐项一致，回放无错误、无残留子进程。MI 产生 26 个计算候选，无 HTTP/适配错误，最终结果撤销、线程停止；SSVEP 方向页恢复、最终失效，SEED 接受窗口数 0（按计划暂停）。

最终审计：正式 48 个清单文件、网页/采集/热点服务配置、`boot.scr`、`image.ub` 和原上传 MP4 均未改变；正式网页 PID 677、采集 PID 24926、重启计数都保持原样。启动 ID 未变；准备、回放和显示临时任务均正常退出，内存页面租约已撤销，实体输出保持关闭。证据分别为 `eeg-page-ram-status-checks.json`、`final_audit.json`、`supplemental-final-audit.json` 与对应播放器报告。

软件验证：系统 Python 23 项、网页脚本检查通过；媒体 Python 37 项（电脑跳过 1 项仅板端 C 测试），板端显示 7 项通过。原特征与私有数组流的五窗口逐位对照最大误差 0。
