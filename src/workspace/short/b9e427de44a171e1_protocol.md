# GuardianLoop结构化EEG污染协议 v1

## 研究问题

固定8通道头戴设备在真实佩戴中会遇到头发阻隔、导电膏不足、电极松动、
导线运动、工频耦合、短时断触和通道接反。研究目标不是让模型无条件输出，
而是在保留干净信号性能的同时：

1. 识别每路信号质量；
2. 对可容忍的坏通道动态降权；
3. 对无法恢复的窗口降低置信度或拒绝预测；
4. 在Z15上实时执行。

## 两个数据域必须分开

- **原始波形域（µV）**：用于Cyton在线质量检测。现有PL阈值为工程阈值：
  窗内最大绝对值100 µV、平均绝对值40 µV、饱和样本数0。它不是医学标准，
  也不直接定义模型训练污染强度。
- **DE特征域**：SEED-VIG缓存是17通道×5频带的差分熵，不包含原始µV。
  训练污染按每段记录的稳健尺度 `IQR / 1.349` 生成，不能把100、160或
  310 µV直接加到DE特征上。

用户当前的约78–310 µV残余波动和曾出现的约24930 µV极端值只作为真实设备
故障形态的线索。等积累足够多干净/松动/头发遮挡记录后，再从真实分布拟合
模拟参数。

## v1污染类型

| 类型 | 现实来源 | DE域近似 | 是否用于训练 |
|---|---|---|---|
| dropout | 接头脱落、数据丢失 | 通道特征置零，质量为0 | 是 |
| flatline | 电极断触或ADC卡死 | 使用低分位常量，时间变化消失 | 是 |
| broadband_noise | 高阻抗、头发、接触不稳 | 全频带DE升高并叠加重尾扰动 | 是 |
| mains_noise | 50 Hz耦合 | 主要抬高gamma，少量影响beta | 是 |
| drift | 导电膏变化、缓慢位移 | 低频更强的平滑随机游走 | 是 |
| burst | 瞬时移动、碰线、眨眼/咬肌伪迹 | 稀疏窗口重尾脉冲 | 是 |
| channel_swap | 接线或软件顺序错误 | 两路完整交换、质量仍显示正常 | 仅评测 |

## 强度与持续时间

- 强度使用0到1的无量纲`severity`，正式结果固定报告0.33、0.66和1.00。
- 训练时每个污染片段覆盖记录的10%–40%，随机选择1–3路。
- 测试时必须固定随机种子，并分别报告损坏1、2、3、4路的鲁棒性曲线。
- 同一被试的污染版本不得跨越训练集和测试集；先按被试划分，再生成污染。
- 测试集同时保留完全干净版本，避免模型只对污染数据有效。

## 第一阶段指标

- 干净性能：Pearson、Spearman、RMSE、MAE、Accuracy、Macro-F1。
- 鲁棒性能：各污染/强度/坏通道数下的上述指标、相对性能下降、鲁棒性曲线面积。
- 质量性能：坏通道检测Precision、Recall、Macro-F1；拒绝预测的coverage-risk曲线。
- 系统性能：Z15端到端延迟、吞吐量、内存、LUT/FF/BRAM/DSP和连续运行稳定性。

## 明确排除

- 不用随机窗口划分代替participant-grouped LOSO。
- 不把模拟污染后的样本冒充真实人体污染。
- 不用放宽PL门限来制造“通过率”。模型降权与硬件安全/饱和拒绝是两层机制。
- 不在测试集上选择阈值、污染参数或最佳通道组合。
