## 候选修复

### 2026-10-13：GUI 初始化差异，尚未硬件验证

公开的 OpenBCI GUI `BoardCyton.pde` 中 Cyton 接入继承 BrainFlow；其当前后端 `openbci_serial_board.cpp` 的准备流程为打开／设置串口 → 发送小写 `v` → 等待 `$$$` 就绪横幅 → 发送 `d` 恢复默认通道配置，随后启动流时发送 `b`。SDK 明确小写 `v` 是 Cyton 外设软复位，不能把它与此前只读大写 `V` 查询等同。

已读到的 Z15 正式代码只在启动中发送 `s`、`c`、八路配置、`b`，不包含这套 `v` 就绪握手；当前本地候选增加了大写 `V` 和逐通道回执，但仍没有 GUI 同等的小写 `v` 初始化。**这是已确认的源码差异和优先验证假设，不是已经确定的故障根因。** 公开 master 源码不能替代用户电脑实际 GUI／BrainFlow 版本或现场指令记录；USB `-32` 的既有证据也不撤销。

本轮仅更正记录并检查源码，未发送 `v` 或 `d`、未安装 BrainFlow、未改正式采集或校准。下一步应在受控隔离下验证初始化差异，保留固定八通道与原始证据，不能未经验证永久加入反复软复位。

来源：[GUI Cyton 接入源码](https://github.com/OpenBCI/OpenBCI_GUI/blob/master/OpenBCI_GUI/BoardCyton.pde)、[BrainFlow 串口后端](https://github.com/brainflow-dev/brainflow/blob/master/src/board_controller/openbci/openbci_serial_board.cpp)、[Cyton SDK](https://docs.openbci.com/Cyton/CytonSDK/)。
